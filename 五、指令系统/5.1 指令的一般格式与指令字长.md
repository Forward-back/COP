# 5.1 指令的一般格式与指令字长

**考纲定位**：计算机组成原理 · 第 5 章 指令系统（5.1）｜重要度 ★★★★｜常见考法：选择题（指令格式、指令字长与机器字长、半字/单字/多字指令、按字节编址的取指次数）

**一句话核心**：指令 = 操作码 + 地址码；指令字长是单条指令占的二进制位数，不是机器字长

## 一、概述

![](../images/Pasted%20image%2020260924185357.png)

**提炼**
- 指令集/指令系统 = 一台计算机全部机器指令的集合，是软件与硬件之间的接口（ISA）
- 指令系统决定软件能看见什么，微架构决定硬件怎么实现；ISA 不变，软件可跨微架构兼容
- 指令系统的设计直接影响编译器复杂度、操作系统接口与硬件成本

**易错**
- ISA 不包含微架构细节（流水线级数、Cache 容量、总线宽度），这些属于实现
- “指令系统相同”不等于“机器性能相同”，同一 ISA 可以有完全不同的微架构

## 二、指令的一般格式

![](../images/Pasted%20image%2020260924185540.png)

**提炼**
- 操作码 OP 指明“做什么”，地址码 A 指明“对谁做”
- 地址码字段的内容不一定是操作数本身，可能是操作数、主存地址、寄存器编号、I/O 端口地址、计算地址用的偏移量
- 寻址方式有两种落点：隐式含在操作码中（MIPS、RISC-V），显式放在地址码字段中（x86）

**易错**
- 地址码里的“地址”不等于主存地址；寄存器编号、I/O 端口号、偏移量都属于地址码
- 地址码字段位数决定可编码的地址空间；要扩大范围，必须增加位数或改用间接/偏移寻址

## 三、指令字长

![](../images/Pasted%20image%2020260924185724.png)

**提炼**
- 指令字长 = 一条指令的二进制位数 = 操作码位数 + 各地址码位数 + 寻址方式字段位数
- 定长指令系统：长度固定、结构规整、译码简单、便于顺序寻址；平均指令字长较长、冗余多、不易扩展
- 变长指令系统：平均指令字长短、冗余少、可扩展；取指与译码复杂，可能多次访存
- 主存按字节编址，因此指令字长必须是字节的整数倍

![](../images/Pasted%20image%2020260924185830.png)

**提炼**
- 指令字长越长，占用主存空间越大，访存时间越长
- 半字长指令：指令字长 = 机器字长 / 2，一次访存可取出 2 条
- 单字长指令：指令字长 = 机器字长，一次访存取出 1 条
- 多字长指令：指令字长 = $k \times$ 机器字长（$k \ge 2$），需要多次访存
- 为提高速度，常用指令通常设计得较短

**易错**
- 指令字长 ≠ 机器字长；定长指令系统也不是“所有指令都等于机器字长”
- “半字长指令一次访存取 2 条”的前提是存储字长 = 机器字长且一次并行读出；按字节编址时，要看一次访存能取多少字节
- 多字长指令的取指次数 = $\lceil \text{指令字长} / \text{存储字长} \rceil$，不是固定 2 次

**知识关联**：指令字长决定 PC 增量（[[5.5 寻址方式——指令寻址]]）；指令字长与地址码个数、操作码扩展互相挤占位数（[[5.2 指令中的地址码]]、[[5.3 指令中的操作码]]）；主存编址单位见第 4 章
