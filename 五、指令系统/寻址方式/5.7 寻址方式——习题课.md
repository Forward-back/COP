# 5.7 寻址方式——习题课

**考纲定位**：计算机组成原理 · 第 5 章 指令系统（5.7）｜重要度 ★★★★★｜常见考法：选择题（EA 计算、寻址方式判断、地址范围、数组访问、大端/小端）

**一句话核心**：先写 EA 公式，再代数；盯住 PC 基准、指令字节数、补码符号扩展、元素大小四个坑

**图旁说明**：题图与解析图原样保留；文字只给“考什么 / 常见错因 / 解题模板”，不转写图中解答

## 例题一：相对寻址

![](../../images/Pasted%20image%2020260928170216.png)

**考什么**：相对寻址 $EA=(PC)+D$；16 位指令、按字节编址，PC 增量为 2

**常见错因**
- 用当前指令地址 2000H 加位移，得 2006H
- 忘记 16 位指令占 2 字节，PC 未更新到 2002H
- 把 06H 当成十进制或忘记位移是补码

**解题模板**
1. 确定指令地址 A 和指令字节数 L
2. 取指后 $PC=A+L$
3. $EA=PC+D$，D 为补码位移
4. 本题：$2000H+2+06H=2008H$，选 C

## 例题二：偏移寻址

![](../../images/Pasted%20image%2020260928170252.png)

**考什么**：偏移寻址的三种形式——相对（PC+位移）、变址（IX+位移）、基址（BR+位移）；间接寻址不属于偏移寻址

**常见错因**
- 把间接寻址当成偏移寻址，因为它也要访问主存
- 把“寄存器内容 + 形式地址”与“寄存器内容作为地址”混淆

**解题模板**
- 看 EA 是否由“某个寄存器内容 + 形式地址 D”构成，是则属于偏移寻址
- 间接寻址的 $EA=(D)$，没有“寄存器内容 + D”的形式
- 本题选 A 间接寻址

## 例题三：变址寻址

![](../../images/Pasted%20image%2020260928170334.png)

**考什么**：变址 $EA=(IX)+D$；先算地址，再按地址取操作数

**常见错因**
- 把 R 的内容 1000H 直接当地址，取 mem[1000H]=2000H
- 把 D=2000H 当地址，取 mem[2000H]=3000H
- 算出 EA 后忘记再取一次操作数

**解题模板**
1. $EA=(R)+D=1000H+2000H=3000H$
2. 操作数 $=mem[EA]=mem[3000H]=4000H$
3. 选 D

## 例题四：直接寻址和基址寻址

![](../../images/Pasted%20image%2020260928170531.png)

**考什么**：指令字段分配 + 补码表示范围；16 个寄存器需要 4 位编号

**常见错因**
- 忘记 16 个寄存器需要 4 位编号，导致偏移位数算错
- 把 16 位补码范围写成 -32767~32767
- 漏算源寄存器或基址寄存器的编号字段

**解题模板**
1. 总位数 32 = 操作码 8 + 源寄存器 4 + 基址寄存器 4 + 偏移 n
2. $n=32-8-4-4=16$
3. 16 位补码范围 $=-2^{15}\sim 2^{15}-1=-32768\sim 32767$
4. 选 A

## 例题五：复合寻址

![](../../images/Pasted%20image%2020260928172555.png)

**考什么**：复合寻址“先变址后间址”的顺序；$EA=((I)+D)$

**常见错因**
- 把“先变址后间址”理解为 $(I+D)$ 或 $(I)+(D)$
- 括号层级看错，少算一次访存

**解题模板**
1. 先变址：$EA_1=(I)+D$
2. 再间址：$EA=(EA_1)$
3. 合写为 $((I)+D)$，选 C

## 例题六：变址寻址的用途

![](../../images/Pasted%20image%2020260928172712.png)

**考什么**：变址寻址适合“首地址固定 + 下标变化”的一维数组顺序访问

**常见错因**
- 选基址寻址（基址适合程序重定位，不适合数组遍历）
- 选相对寻址（相对适合位置无关代码/转移）
- 选直接寻址（地址固定，无法遍历）

**解题模板**
- 看到“数组首地址固定、下标按顺序变化”，选变址寻址
- 看到“程序重定位、多道程序”，选基址寻址
- 看到“转移指令、位置无关”，选相对寻址
- 本题选 D 变址寻址

## 例题七：变址寻址

![](../../images/Pasted%20image%2020260928172813.png)

**考什么**：元素地址 = 首地址 + 下标 × 元素大小；变址寄存器存的是下标，不是字节地址

**常见错因**
- 忘记 double 占 8 字节，直接用 0x100=256 作下标
- 把变址寄存器内容当成字节地址
- 忘记“取完后内容自动加 1”是下标加 1，不是地址加 1

**解题模板**
1. 偏移 = 目标地址 - 首地址 = $2100H-2000H=100H=256$
2. 下标 = 偏移 / 元素大小 = $256/8=32$
3. 选 B

## 例题八：大端方式与基址寻址

![](../../images/Pasted%20image%2020260928172926.png)

**考什么**：基址寻址 $EA=(BR)+$ 符号扩展(位移)；大端存储的字节顺序

**常见错因**
- 忘记 FF12H 是补码负数，直接加 +FF12H
- 符号扩展错误：FF12H 应扩展为 FFFFFF12H，而不是 0000FF12H
- 大端/小端搞反，把 LSB 放在低地址

**解题模板**
1. 位移 FF12H 是 16 位补码，符号扩展为 FFFFFF12H（即 -00EEH）
2. $EA=F0000000H+FFFFFF12H=EFFFFF12H$（32 位模运算）
3. 大端：MSB 放低地址；数据 12 34 FF 00 依次放在 EFFFFF12H~EFFFFF15H
4. LSB=00 在 EFFFFF15H，选 D

**上图错误原因**

![](../../images/Pasted%20image%2020260928172954.png)

- 核心错误是把 FF12H 当成无符号数直接相加
- 正确做法：先按补码求真值，再符号扩展，最后与基址相加

## 通用检查清单

| 题型 | 第一步 | 关键提醒 |
| --- | --- | --- |
| 相对寻址 | 算取指后 PC | PC 增量 = 指令字节数 |
| 变址寻址 | $EA=(IX)+D$ | IX 变、D 不变 |
| 基址寻址 | $EA=(BR)+D$ | 位移先符号扩展 |
| 复合寻址 | 从最内层括号算起 | 每层括号对应一次访存 |
| 数组访问 | 偏移 = 目标 - 首地址 | 下标 = 偏移 / 元素大小 |
| 大端/小端 | 先确定 MSB/LSB | 大端低地址放 MSB |
