## 三、操作数寻址总表（九种基本 + 复合）

| 寻址方式 | EA | 操作数访存次数（不含取指） | 一句话用途 | 核心易错 |
| --- | --- | :---: | --- | --- |
| 立即寻址 | 无，D 即操作数 | 0 | 常量、初值 | D 是数不是地址 |
| 直接寻址 | $EA=D$ | 1 | 访问固定主存单元 | D 位数限制范围 |
| 寄存器寻址 | $EA=R_D$ | 0 | 寄存器间运算 | EA 是编号不是内容 |
| 间接寻址 | $EA=(D)$ | 2（多级更多） | 扩大寻址范围 | D 不是 EA |
| 寄存器间接 | $EA=(R_D)$ | 1 | 指针访问 | 与寄存器寻址差一次访存 |
| 相对寻址 | $EA=(PC)+D$ | 1 | 位置无关代码、转移 | PC 用更新后的值 |
| 变址寻址 | $EA=(IX)+D$ | 1 | 数组遍历 | IX 变、D 不变 |
| 基址寻址 | $EA=(BR)+D$ | 1 | 程序重定位 | BR 不变、D 变 |
| 堆栈寻址 | $EA=(SP)$ | 1（硬堆栈 0） | 现场保护、零地址 | SP 指向约定 |
| 复合寻址 | 按组合，如 $((PC)+D)$ | 2 | CISC 复杂寻址 | 括号由内向外 |

## 四、核心公式

- 指令字长 $=$ 操作码位数 $+$ 各地址码位数 $+$ 寻址方式字段位数
- 定长操作码：$x \le 2^n$
- 扩展操作码：第 $k$ 级可用编码数 $= R_{k+1} \times 2^a$，其中 $R_{k+1}$ 为上一级剩余前缀数，$a$ 为地址码字段位数
- 顺序寻址：$PC \leftarrow PC + L$，$L$ 为当前指令字节数
- 相对寻址：$EA=(PC)+D$，PC 为取指后已更新的值
- 变址寻址：$EA=(IX)+D$
- 基址寻址：$EA=(BR)+D$
- 间接寻址：$EA=(D)$
- 寄存器间接：$EA=(R_D)$
- 元素地址 $=$ 首地址 $+$ 下标 $\times$ 元素大小

## 五、易混术语

| 术语 | 含义 | 易混点 |
| --- | --- | --- |
| 指令字长 | 一条指令的二进制位数 | ≠ 机器字长 |
| 机器字长 | CPU 一次能处理的二进制位数 | 与指令字长无固定关系 |
| 存储字长 | 一个存储单元的位数 | 与编址单位不同 |
| 形式地址 D | 指令中给出的地址字段 | 不一定是 EA |
| 有效地址 EA | 操作数所在主存单元地址 | 寄存器寻址时是编号 |
| 指令寻址 | 找下一条指令 | 与操作数寻址平行 |
| 操作数寻址 | 找操作数 | 九种方式 |
| 定长操作码 | 操作码位数固定 | ≠ 指令字长固定 |
| 扩展操作码 | 用前缀扩展增加指令条数 | 短码不能是长码前缀 |
| CISC | 复杂指令集 | ≠ 一定慢 |
| RISC | 精简指令集 | ≠ 一定没有微程序 |
