# 5.9 复杂指令集计算机和精简指令集计算机

**考纲定位**：计算机组成原理 · 第 5 章 指令系统（5.9）｜重要度 ★★★★｜常见考法：选择题（CISC/RISC 特点、判断正误、控制器与流水线适配）

**一句话核心**：CISC 用复杂指令换代码密度与兼容性；RISC 用简单指令换流水线与频率

**图旁说明**：4 张课件图保留；文字只补对比维度与设错，不重复图内定义

## 一、CISC 和 RISC 概述

![](../images/Pasted%20image%2020260928191139.png)

**提炼**
- 指令系统朝两个方向发展：增加复杂指令/寻址方式（CISC），或减少指令种类/规范格式（RISC）
- CISC 典型：x86（课件另列 IA-64）；RISC 典型：ARM、MIPS、RISC-V
- 两种方向都在解决“如何让指令系统更好用、更高效”，只是取舍不同

**易错**
- CISC/RISC 是设计理念，不是“指令数量多/少”的绝对划分
- 现代 x86 内部也把复杂指令翻译成 RISC 式微操作，不能只看外部 ISA

## 二、CISC 讲解

### 2.1 CISC 的设计需求

![](../images/Pasted%20image%2020260928191329.png)

**提炼**
- 缩小高级语言与机器语言之间的语义差距，降低编译器设计难度
- 保证软件向后兼容：新机型包含旧机型指令，导致指令越来越多
- 更好支持操作系统：增加系统指令、特权指令
- 结果：指令系统庞大复杂，指令数量常达数百条以上

**易错**
- 向后兼容是 CISC 指令膨胀的主因之一
- 兼容性针对“指令集/二进制”，不是“微架构”；同一 ISA 可以有完全不同的实现

### 2.2 CISC 的特点

![](../images/Pasted%20image%2020260928191416.png)

**提炼**
- 指令数量多、长度不固定、格式多、寻址方式多
- 对访存指令不加限制，运算指令可以直接访存
- 各指令使用频率差异大、执行时间差异大，多数指令需多个时钟周期
- 多采用微程序控制器

**易错**
- CISC 指令多 ≠ 所有指令都常用；80/20 定律：20% 的指令占 80% 的使用频率
- CISC 多采用微程序控制，但不是“必须”；现代 CISC 可能采用硬布线+微码混合
- 指令执行时间差异大，不利于流水线；但 CISC 并非不能流水

## 三、RISC 讲解

![](../images/Pasted%20image%2020260928191454.png)

**提炼**
- 精选使用频率高的简单指令，复杂功能由简单指令组合实现
- 指令长度固定、格式少、寻址方式少
- 只有 Load/Store 访存，运算在寄存器之间进行
- 通用寄存器多，减少访存
- 采用流水线、硬布线控制，重视编译优化

**易错**
- RISC 不是“没有复杂功能”，而是“复杂功能用简单指令组合”
- RISC 不是“指令少到几十条”，不同架构差异大；关键是规整
- RISC 采用硬布线控制，但不是“绝对不能有微程序”
- Load/Store 限制是“只有这两类指令访存”，不是“只有两条指令”

## 四、408 高频对比表

| 维度 | CISC | RISC |
| --- | --- | --- |
| 指令数量 | 多，通常数百条以上 | 少，精选高频指令 |
| 指令长度 | 可变，格式多 | 固定，格式少 |
| 寻址方式 | 多，支持复杂寻址 | 少，寻址简单 |
| 访存限制 | 运算指令可直接访存 | 只有 Load/Store 访存 |
| 寄存器数量 | 较少 | 较多 |
| 控制器 | 多为微程序 | 多为硬布线 |
| 流水线 | 较难，指令执行时间差异大 | 容易，指令规整 |
| 编译优化 | 依赖复杂指令/编译器 | 重视编译优化与寄存器分配 |
| 软件兼容 | 强，新机型常包含旧指令 | 较弱，指令集变动影响大 |
| 典型架构 | x86（课件另列 IA-64） | ARM、MIPS、RISC-V |

**提炼**
- 一条主线：CISC 用“复杂指令”减少程序指令条数；RISC 用“简单指令+流水线”提高执行效率
- 408 判断口诀：指令定长、格式少、寻址少、Load/Store、寄存器多、硬布线、流水线 → RISC

**易错**
- “CISC 一定比 RISC 慢”错：性能取决于实现、工艺、编译器
- “RISC 一定没有微程序”错：早期 RISC 也有微码，现代实现更复杂
- “RISC 指令一定少”不严谨：关键是规整与高频精选
- “CISC 不支持流水线”错：x86 也深度流水，只是代价更高
- “CISC 兼容性一定好”要限定“同一指令集家族”
- 课件把 IA-64 归入 CISC；严格说 IA-64 属于 EPIC/VLIW，408 记 x86 为 CISC 代表即可
