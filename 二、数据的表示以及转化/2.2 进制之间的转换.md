# 2.2 进制之间的转换

**考纲定位**：计算机组成原理 · 第 2 章 数据的表示和运算（2.2）｜重要度 ★★★★｜常见考法：选择题（进制转换、二/八/十六进制互转、补零、按权展开）

**一句话核心**：任意进制都按“位权 × 系数”展开；二/八/十六进制按 3/4 位分组；十进制整数除基取余、小数乘基取整

## 一、任意进制按权展开的通式

![](../images/Pasted%20image%2020260826185556.png)

**公式**

$$N=\sum_{i=-m}^{n-1} d_i r^i$$

- $n$ 位整数位，$m$ 位小数位
- $r$ 为基数：2、8、10、16
- $d_i$ 为第 $i$ 位的数字，$0\le d_i<r$

**例**：$1011.101_2=1\times2^3+0\times2^2+1\times2^1+1\times2^0+1\times2^{-1}+0\times2^{-2}+1\times2^{-3}=11.625$

**易错**
- 位权从小数点向两侧展开，小数位是负指数
- 基数为 16 时，A~F 分别表示 10~15
- 不要漏掉 0 系数项

## 二、各进制的具体表示

| 进制 | 基数 | 数字 | C 语言常见写法 |

| 二进制 | 2 | 0,1 | `0b` 前缀（部分编译器/C23） |

## 三、进制转换

### 3.1 任意进制转十进制

![](../images/Pasted%20image%2020260826190128.png)

**方法**
- 按位权展开，逐项相乘后相加
- 整数部分从右往左权为 $r^0,r^1,\dots$
- 小数部分从左往右权为 $r^{-1},r^{-2},\dots$

### 3.2 二进制与八进制、十六进制的转化

![](../images/Pasted%20image%2020260826190247.png)

#### 3.2.1 二进制、八进制

- 二进制转八进制：从低位到高位，每 3 位一组，不足 3 位在高位补 0
- 八进制转二进制：每一位展开成 3 位二进制
- 分组从小数点向两侧进行

#### 3.2.2 二进制、十六进制

- 二进制转十六进制：从低位到高位，每 4 位一组，不足 4 位在高位补 0
- 十六进制转二进制：每一位展开成 4 位二进制
- 八进制与十六进制互转，可通过二进制作为桥梁

![](../images/Pasted%20image%2020260826190840.png)

- 分组必须从小数点开始向两侧分，不是从最左端开始
- 不足位在高位补 0；小数部分不足位在低位补 0
- 十六进制 A~F 不要写成 10~15 两个字符

### 3.3 十进制转任意进制

![](../images/Pasted%20image%2020260826191046.png)

#### 3.3.1 除基取余（整数部分）

通过按权展开的通式发现，可以通过原式除以基数而后取余数的方式，得到当前最低位的数字

![](../images/Pasted%20image%2020260826191300.png)

![](../images/Pasted%20image%2020260826191430.png)

**步骤**
1. 整数除以基数，余数为最低位
2. 商继续除以基数，余数为次低位
3. 直到商为 0
4. 余数从下往上读

**例**：$13_{10}=1101_2$

#### 3.3.2 乘基取整（小数部分）

![](../images/Pasted%20image%2020260826191515.png)

![](../images/Pasted%20image%2020260826191535.png)

**步骤**
1. 小数乘以基数，取整数部分为最高小数位
2. 剩下的小数部分继续乘基数
3. 直到小数部分为 0，或达到精度要求
4. 整数部分从上往下读

**例**：$0.625_{10}=0.101_2$

**易错**
- 整数部分“除基取余”的余数要倒序读
- 小数部分“乘基取整”的整数部分要正序读
- 小数不一定能有限表示；题目会给出位数
- 整数和小数要分开转换，最后拼接

## 四、总结

![](../images/Pasted%20image%2020260826191653.png)

| 转换方向 | 方法 | 读取顺序 |
| --- | --- | --- |
| 任意进制 → 十进制 | 按权展开 | 直接相加 |
| 二进制 → 八进制 | 3 位一组 | 从低位向高位 |
| 二进制 → 十六进制 | 4 位一组 | 从低位向高位 |
| 十进制整数 → 任意进制 | 除基取余 | 余数倒序 |
| 十进制小数 → 任意进制 | 乘基取整 | 整数正序 |
