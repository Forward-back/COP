# 2.9 浮点数的规格化

**考纲定位**：计算机组成原理 · 第 2 章 数据的表示和运算（2.9）｜重要度 ★★★★★｜常见考法：选择题/大题（规格化标准、左规/右规、阶码调整、范围）

**一句话核心**：规格化让尾数最高有效位非 0，从而表示唯一、精度最高；左规降阶，右规升阶

## 一、为何规格化

在 [[2.8 浮点数的表示形式以及表示范围]] 中，浮点数可采用类似科学计数法的表示方法，但一个十进制数可以有不同的科学计数法表示（只需调整幂的大小），所以需要规格化

![](../../images/Pasted%20image%2020260827202507.png)

**目的**
- 表示形式唯一
- 充分利用尾数位数，精度最高
- 便于比较大小和运算

## 二、规格化处理

### 2.1 规格化的标准

![](../../images/Pasted%20image%2020260827202612.png)

**注**：让尾数的最高位有意义，判定取决于基数
- 基数为 2：最高数值位必须为 1
- 基数为 8：最高 3 位不能全为 0
- 基数为 16：最高 4 位不能全为 0
- 以此类推

**补码尾数**
- 规格化判据是“符号位与最高数值位不同”
- 正数：0.1xxx；负数：1.0xxx
- 不要与原码判据混用

### 2.2 规格化的方法

![](../../images/Pasted%20image%2020260827203001.png)

**左规**
- 尾数左移 1 位，阶码减 1
- 用于尾数绝对值太小、最高有效位为 0 的情况
- 可能使阶码下溢

**右规**
- 尾数右移 1 位，阶码加 1
- 用于尾数绝对值 ≥1（溢出）的情况
- 可能使阶码上溢

**举例**

![](../../images/Pasted%20image%2020260827202849.png)

**注**：对于基数对精度的影响的解释

![](../../images/Pasted%20image%2020260827203107.png)

- 基数越大，留给最高位可以取若干无效 0 的权限就越大
- 基数大，范围大，但同样尾数位数下精度可能下降

**易错**
- 左规阶码减，右规阶码加；不要反
- 原码尾数与补码尾数的规格化判据不同
- 基数为 8/16 时，不是看最高 1 位，而是看最高 3/4 位
- 规格化可能改变阶码，进而引起上溢/下溢

## 三、规格化后浮点数表示范围

![](../../images/Pasted%20image%2020260827203251.png)

**规律**
- 规格化后尾数范围变小，但表示精度提高
- 最大正数、最小正数、最大负数、最小负数仍由阶码和尾数共同决定
- 规格化后的范围比非规格化略小，但表示唯一

**易错**
- 规格化不是“扩大范围”，而是“提高精度、唯一表示”
- 规格化后阶码可能变化，范围边界也要跟着变

**解题模板**
1. 写出阶码、尾数、基数
2. 检查尾数最高有效位
3. 不满足 → 左规或右规
4. 每次移位同步调整阶码
5. 检查阶码上溢/下溢

**易错**
- 移位方向与阶码调整方向要对应
- 补码负数右移补符号位，左移低位补 0
- 规格化后尾数符号位不能变（除非溢出）
