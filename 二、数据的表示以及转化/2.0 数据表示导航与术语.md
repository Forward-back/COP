## 三、核心公式总表

**进制**
- $N=\sum d_i r^i$
- 二进制 ↔ 八进制：3 位一组
- 二进制 ↔ 十六进制：4 位一组
- 十进制整数 → 任意进制：除基取余，余数倒序
- 十进制小数 → 任意进制：乘基取整，整数正序

**定点编码（N 位字长）**
- 原码：符号位 + 绝对值
- 反码：正数同原码；负数数值位取反
- 补码：正数同原码；负数反码末位加 1
- 移码：补码符号位取反
- 补码范围：$-2^{N-1}\sim2^{N-1}-1$
- 原码/反码范围：$-(2^{N-1}-1)\sim2^{N-1}-1$
- 补码唯一零；原码/反码双零

**浮点**
- $N=r^E\times M$
- 阶码决定范围，尾数决定精度
- 规格化：基数 2 时最高数值位为 1
- 左规：尾数左移，阶码减 1
- 右规：尾数右移，阶码加 1

**IEEE 754**
- 单精度：1+8+23，bias 127
- 双精度：1+11+52，bias 1023
- 真值：$(-1)^S\times1.F\times2^{E-\text{bias}}$
- 阶码全 0：非规格化数/0
- 阶码全 1：∞/NaN

**C 类型转换**
- 同字长：按位重新解释，值可能变
- 短 → 长：源无符号零扩展，源有符号符号扩展，真值不变
- 长 → 短：截断低位，值可能变
- float/double → int：向 0 截断，超范围 UB
- int → float：超过 $2^{24}$ 可能丢精度
- int → double：32 位精确，64 位可能丢精度

## 四、易混术语

| 术语 | 含义 | 易混点 |
| --- | --- | --- |
| 机器数 | 计算机内部 0/1 位串 | 不是真值 |
| 真值 | 带符号的实际数值 | 人类书写 |
| 原码 | 符号 + 绝对值 | 双零，不能直接运算 |
| 反码 | 负数数值位取反 | 双零，过渡编码 |
| 补码 | 模运算表示 | 唯一零，多一个最小负数 |
| 移码 | 补码符号位取反 | 1 正 0 负 |
| 阶码 | 浮点指数 | 决定范围 |
| 尾数 | 浮点有效数字 | 决定精度 |
| 规格化 | 尾数最高位有效 | 左规/右规 |
| 隐藏位 | IEEE 尾数隐含 1 | 非规格化数为 0 |
| 偏置 | 阶码平移量 | 单 127，双 1023 |
| 符号扩展 | 高位补符号位 | 真值不变 |
| 零扩展 | 高位补 0 | 负数真值会变 |
| 截断 | 保留低位 | 不是四舍五入 |
