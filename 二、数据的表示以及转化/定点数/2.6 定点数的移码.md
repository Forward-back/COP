# 2.6 定点数的移码

**考纲定位**：计算机组成原理 · 第 2 章 数据的表示和运算（2.6）｜重要度 ★★★★｜常见考法：选择题（移码定义、与补码关系、零的表示、比较大小）

**一句话核心**：移码把真值整体平移，使二进制无符号值随真值单调递增；符号位 1 正 0 负，与补码正好相反

## 一、定义

![](../../images/Pasted%20image%2020260826202359.png)

$$\text{移码}=2^{N-1}+x$$

- $N$ 位字长，偏置常数 $2^{N-1}$
- 表示范围：$-2^{N-1}\le x\le2^{N-1}-1$
- 符号位：1 表示正数，0 表示负数
- 移码 = 补码的符号位取反，数值位不变

**注意**：移码主要用于浮点数的阶码，也可用于定点整数；定点小数不使用移码

**注意**：真值 0 在移码中只有一种表示（`1000...000`）

**例**：4 位字长
- $x=+3$：移码 = $8+3=11$ = `1011`
- $x=-3$：移码 = $8-3=5$ = `0101`
- $x=0$：移码 = `1000`

## 二、总结

![](../../images/Pasted%20image%2020260826202649.png)

| 项目 | 移码 |
| --- | --- |
| 定义 | $2^{N-1}+x$ |
| 符号位 | 1 正 0 负 |
| 零 | 唯一 |
| 范围 | $-2^{N-1}\sim2^{N-1}-1$ |
| 与补码 | 符号位相反，数值位相同 |
| 用途 | 浮点数阶码；便于比较大小 |

**易错**
- 移码符号位与补码相反，1 是正数
- 移码的 0 是 `1000...000`，不是全 0
- 移码比较大小可直接按无符号数比较
- 移码不是“小数点移动”，是整体平移
- 不能把移码误用于定点小数
