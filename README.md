# 计算机组成原理学习笔记

本仓库是我学习 **B 站「湖科大」《计算机组成原理》网课** 时整理的个人笔记，按课程章节顺序编排，主要用于 408 考研复习和日常查阅。

笔记以 Markdown 撰写（Obsidian 格式），并同步导出了排版好的 PDF 版本，可按需选择。

## 内容概览

- 共 **8 章、150 篇笔记**，覆盖计算机组成原理课程主体内容
- 每章按知识点拆分小节，配有文字说明、图示、表格与公式推导
- 公式使用 LaTeX 编写，PDF 版已渲染为排版公式

| 章节 | 主题 | 篇数 |
| :--- | :--- | ---: |
| 一、概论 | 计算机系统组成、发展、层次结构、性能指标 | 8 |
| 二、数据的表示以及转化 | 进制转换、定点数/浮点数表示、IEEE 754 | 14 |
| 三、运算法则与运算器 | 移位、加减乘除运算及硬件实现 | 23 |
| 四、存储器 | 存储层次、SRAM/DRAM、Cache、虚拟存储器 | 40 |
| 五、指令系统 | 指令格式、寻址方式、CISC/RISC | 10 |
| 六、中央处理器 | CPU 结构、数据通路、控制器、流水线 | 34 |
| 七、总线 | 总线分类、仲裁、定时、常用总线 | 9 |
| 八、IO系统 | IO 接口、中断、DMA | 12 |

## 两种格式

### Markdown 版

- 原始笔记，推荐用 [Obsidian](https://obsidian.md/) 打开获得最佳阅读体验
- 图片使用相对路径（`images/`），同时兼容 Typora、VS Code 等标准 Markdown 渲染器
- 方便检索、修改和参与贡献

### PDF 版

- 已排版的 A4 文档，适合打印、平板阅读或不方便使用 Markdown 编辑器的场景
- 公式、表格、代码块与插图均已渲染

## 使用方式

```bash
git clone https://github.com/Forward-back/COP.git
```

- 阅读 Markdown：用 Obsidian 打开仓库根目录作为 vault（或将整个目录导入现有 vault）
- 阅读 PDF：直接进入 `PDF版/`，目录结构与 Markdown 版一致
