## 组织方式

- **每章先看 `X.0`**：包含章节地图、主线、核心公式、易混术语、跨章接口
- **编号冲突用后缀**：如 `4.5A/4.5B`、`4.25A/4.25B/4.25C`、`2.7A/2.10A/2.11A`
- **每篇结构**：考纲定位 → 一句话核心 → 提炼/易错 → 知识关联；计算型小节附模板，习题课用“考什么/常见错因/解题模板”三行卡
- **图片**：保留课件原图，文字只做提炼、公式、易错与答疑，不重复图内定义
- **链接**：使用 Obsidian wikilink，图片使用相对路径，兼容 Obsidian、Typora、VS Code

## 两种格式

### Markdown 版

- 原始笔记，推荐用 [Obsidian](https://obsidian.md/) 打开获得最佳阅读体验
- 图片使用相对路径（`images/`），同时兼容 Typora、VS Code 等标准 Markdown 渲染器
- 支持 wikilink、LaTeX 公式、表格与代码块
- 方便检索、修改和参与贡献

### PDF 版

- 已排版的 A4 文档，适合打印、平板阅读或不方便使用 Markdown 编辑器的场景
- 公式、表格、代码块与插图均已渲染
- 由当前 Markdown 导出，内容与 Markdown 版一致

## 使用方式

```bash
git clone https://github.com/Forward-back/COP.git
```

- 阅读 Markdown：用 Obsidian 打开仓库根目录作为 vault（或将整个目录导入现有 vault）
- 阅读 PDF：直接进入 `PDF版/`，目录结构与 Markdown 版一致
- 建议先读各章 `X.0` 导航，再进入具体小节
