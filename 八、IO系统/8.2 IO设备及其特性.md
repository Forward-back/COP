# 8.2 I/O 设备及其特性

**考纲定位**：计算机组成原理 · 第 8 章 I/O 系统（8.2）｜重要度 ★★｜常见考法：概念选择题（设备分类、三大特性）

**一句话核心**：I/O 设备是计算机与外部世界交换数据的装置，具有异步性、实时性、独立性

## 一、定义

![](../images/Pasted%20image%2020261102195422.png)

- I/O 设备 = 计算机与人（或其他系统）进行数据交互的装置，也称外部设备（外设）
- 输入设备：把数据、文字、图片、音频、视频等转换成计算机可以识别的二进制信息
- 输出设备：把计算机的处理结果转换成数字、文字、图像、声音、视频等
- 注意：外设不只有输入/输出设备，磁盘、光盘等存储设备也属于外设

## 二、种类与差异

| 差异维度 | 典型情况 |
|---|---|
| 结构 | 机械式、电子式 |
| 信号 | 数字信号、模拟信号 |
| 性能 | 慢速（串口设备）、高速（网络设备） |
| 访问方式 | 顺序访问（字符设备）、随机访问（块设备） |

- 设备差异越大，越需要 I/O 接口与驱动程序做屏蔽
- 408 常把“字符设备/块设备”“顺序访问/随机访问”放在一起考对应关系

## 三、三大特性

![](../images/Pasted%20image%2020261102195501.png)

**异步性**
- CPU 运算速度极快（纳秒级），I/O 设备数据处理/传输速度极慢（毫秒级甚至更慢）
- 若强制“公共时钟同步”，CPU 需要持续等待慢速设备，导致运算资源大量浪费
- 采用异步通信：设备自主准备数据时，CPU 执行其他任务；设备完成后再通过中断通知 CPU
- 通过“并行 + 中断”机制，让 CPU 与 I/O 设备解耦，各自按自己的节奏工作

**实时性**
- 不同速度的 I/O 设备，在准备好数据后都需要 CPU 及时响应
- 慢速设备（键盘、鼠标）不及时响应，影响用户体验
- 高速设备（万兆网卡、高速数据采集卡）不及时处理，会产生数据丢失
- 实时测控设备不及时处理，可能导致严重事故

**独立性**
- 通过软硬件分层抽象，屏蔽不同 I/O 设备的差异，降低 CPU 与 I/O 设备的连接、控制复杂度
- 硬件层面：各类 I/O 设备采用标准总线接口与 CPU 连接，使不同设备以一致方式接入系统
- 软件层面：不同 I/O 设备采用统一的访问调用接口，使输入输出与具体设备类型无关，程序无需关注设备硬件细节

## 四、易错点

- 异步性不是“设备之间异步”，而是 CPU 与设备速度不匹配
- 实时性不是“所有设备都要实时”，而是不同设备有不同响应要求
- 独立性不是“设备物理上独立”，而是软硬件接口对上层屏蔽差异
- 外设不等于输入/输出设备，磁盘等存储设备也属于外设
