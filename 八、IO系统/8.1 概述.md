# 8.1 I/O 系统概述

**考纲定位**：计算机组成原理 · 第 8 章 I/O 系统（8.1）｜重要度 ★★｜常见考法：章节框架与概念选择题，直接计算少

**一句话核心**：I/O 系统负责 CPU／主存与外部设备之间的信息交换，由硬件（设备、接口、总线、管理部件）与软件（驱动、访问接口、用户程序）共同构成

![](../images/Pasted%20image%2020261102195335.png)

## 一、I/O 系统的作用

- CPU 与外部设备（I/O 设备）之间的信息交换
- 外部设备（I/O 设备）与主存之间的信息交换
- 一句话：I/O 系统是计算机与外部世界交换数据的通道，不只是“插在主机上的设备”

## 二、I/O 系统的构成

| 层面 | 组成 | 作用 |
|---|---|---|
| 硬件 | I/O 设备、I/O 接口、I/O 管理部件、总线 | 完成设备接入、寻址、数据缓冲与控制 |
| 软件 | 驱动程序、软件访问接口、用户程序 | 屏蔽设备差异，向用户提供统一访问方式 |

- 硬件是“通路”，软件是“使用通路的方式”，两者缺一不可
- I/O 接口是硬件侧的关键：设备必须通过接口才能挂到总线上
- 驱动程序是软件侧的关键：它直接操作接口中的寄存器

## 四、408 重点

- 三种基本控制方式：程序查询、中断驱动、DMA
- I/O 接口：接口 vs 端口、DBR/DCR/DSR、统一编址 vs 独立编址
- 中断：中断隐指令、中断向量、单级/多重中断、屏蔽字
- DMA：DMA 流程、DREQ/DACK、HOLD/HLDA、三种争用方式
- 常见设备只作了解，不深挖内部机械结构

## 五、易错点

- I/O 系统 ≠ I/O 设备：前者是硬件 + 软件的整体，后者只是硬件
- I/O 控制方式 ≠ I/O 设备类型：同一种设备可以配不同的控制方式
- 接口 ≠ 端口：接口是整块适配电路，端口是接口中可被 CPU 寻址的寄存器
- 本章的“I/O”与操作系统的“I/O 管理”视角不同：计组看硬件通路，OS 看软件抽象
