# 3.22 运算器

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.22）｜重要度 ★★★★★｜常见考法：选择题（ALU 功能、ALUop、标志位、数据通路接口）

**一句话核心**：运算器 = ALU + 寄存器 + 数据通路；ALU 负责算，寄存器负责存，标志位负责记录结果特征

## 一、概述

![](../images/Pasted%20image%2020260909175309.png)

**组成**
- 算术逻辑单元 ALU：执行加减、逻辑、移位等运算
- 寄存器组：存放操作数、结果、状态
- 数据通路：连接寄存器、ALU、总线
- 控制信号：选择运算、控制数据流向

**提炼**
- 运算器是 CPU 的执行部件
- ALU 是组合逻辑，输出结果和标志位
- 寄存器是时序部件，保存操作数和结果

**易错**
- 运算器不只是 ALU；还包括寄存器和数据通路
- ALU 不存储数据，结果要写回寄存器
- 标志位是运算的副产物，不是数据

## 二、算数逻辑单元ALU

![](../images/Pasted%20image%2020260909175442.png)

**ALU 输入输出**
- 输入：操作数 $A,B$，控制信号 ALUop
- 输出：结果 $F$，标志位 ZF/SF/CF/OF

**ALUop 控制**
- 00：与运算
- 01：或运算
- 10：加运算
- 其他编码：减、异或、移位等，按题目/教材约定

**标志位**

![](../images/Pasted%20image%2020260909175657.png)

| 标志 | 含义 | 典型判断 |
| --- | --- | --- |
| ZF | 结果为零 | 结果全 0 |
| SF | 结果符号 | 结果最高位 |
| CF | 无符号进位/借位 | 加法进位、减法借位 |
| OF | 有符号溢出 | $C_n\oplus C_{n-1}$ |

**提炼**
- ALUop 选择运算类型，不是指令操作码的全部
- 标志位由 ALU 或独立标志寄存器产生
- 条件转移指令读取标志位，不直接读 ALU 结果

**易错**
- ALUop 与指令操作码不是一回事；操作码还要译码成 ALUop
- CF 与 OF 不同：CF 看无符号，OF 看有符号
- 逻辑运算通常使 CF=0、OF=0，但不同架构可能不同
- 标志位是否更新由控制信号决定，不是所有运算都更新

## 三、运算器与数据通路的接口

**数据流**
1. 操作数从寄存器/总线送入 ALU 的 A、B 端
2. ALUop 选择运算
3. 结果 F 写回寄存器或送总线
4. 标志位写入标志寄存器
5. 控制信号决定是否写回、是否更新标志

**单总线/多总线**
- 单总线：同一时刻只能传一个数据，需要暂存器
- 多总线：可同时传多个操作数，速度更快
- 具体数据通路见第 6 章

**易错**
- ALU 输出不能直接连总线而不经过暂存/寄存器
- 写回时机由时钟控制
- 标志位更新与结果写回可能分开控制
