## 三、核心公式总表

**移位**
- 逻辑左移：低位补 0；逻辑右移：高位补 0
- 算术右移：高位补符号位；算术左移：低位补 0
- 循环移位：移出位补到另一端；带 CF 构成 $(w+1)$ 位环

**补码加减**
- $[x+y]_补=[x]_补+[y]_补 \pmod{2^n}$
- $[x-y]_补=[x]_补+[-y]_补 \pmod{2^n}$
- $[-y]_补=\overline{[y]_补}+1$
- $OF=C_n\oplus C_{n-1}$
- 变形补码：$OF=S_{s1}\oplus S_{s2}$

**加法器**
- $S=A\oplus B\oplus C_i$
- $C_o=AB+AC_i+BC_i$
- $G_i=A_iB_i$，$P_i=A_i\oplus B_i$
- $C_{i+1}=G_i+P_iC_i$
- 组：$G^*=G_3+P_3G_2+P_3P_2G_1+P_3P_2P_1G_0$，$P^*=P_3P_2P_1P_0$

**乘法**
- 无符号：部分积右移，$Q_0$ 决定加不加
- 原码：符号异或，数值位无符号乘
- Booth：$Q_iQ_{i-1}=01$ 加 $M$，$10$ 减 $M$，其余不加不减
- 阵列：与门阵列 + 加法器阵列，面积 $O(n^2)$

**除法**
- 恢复余数：不够减则加回除数
- 加减交替：余数为正下一步减，为负下一步加
- 补码：第一拍定商符；同号商 1，异号商 0；末位恒置 1；余数修正

**浮点**
- 加减：对阶 → 尾数加减 → 规格化 → 舍入 → 溢出
- 乘法：阶码相加，尾数相乘，规格化
- 除法：阶码相减，尾数相除，规格化
- IEEE：$E=E_x+E_y-\text{bias}$（乘），$E=E_x-E_y+\text{bias}$（除）

## 四、易混术语

| 术语 | 含义 | 易混点 |
| --- | --- | --- |
| 逻辑移位 | 无符号位串移位 | 右移补 0 |
| 算术移位 | 有符号数移位 | 右移补符号位 |
| 循环移位 | 移出位补到另一端 | 带 CF 是 $(w+1)$ 位环 |
| CF | 无符号进位/借位 | 与 OF 不同 |
| OF | 有符号溢出 | $C_n\oplus C_{n-1}$ |
| 半加器 | 无进位输入 | 全加器有 $C_i$ |
| 串行进位 | 进位逐级传 | 延迟 $O(n)$ |
| 先行进位 | G/P 提前算进位 | 延迟 $O(\log n)$ |
| 原码乘法 | 符号与数值分开 | 符号异或 |
| Booth | 补码乘法重编码 | 看相邻两位 |
| 恢复余数 | 不够减加回 | 多一次加法 |
| 加减交替 | 不够减不加回 | 下一步改加 |
| 对阶 | 小阶向大阶看齐 | 尾数右移 |
| 规格化 | 尾数恢复到规定范围 | 左规/右规 |
| 隐藏位 | IEEE 尾数隐含 1 | 非规格化数隐藏位 0 |
