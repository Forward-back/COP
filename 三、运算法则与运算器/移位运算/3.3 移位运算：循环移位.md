# 3.3 移位运算：循环移位

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.3）｜重要度 ★★★★｜常见考法：选择题（带/不带 CF、循环左/右移、多字长移位、与逻辑/算术移位区别）

**一句话核心**：循环移位把移出的位补到另一端，数据位不丢；带 CF 时 CF 也在环上，构成 $(w+1)$ 位大环

## 一、规则

![](../../images/Pasted%20image%2020260829185100.png)

**核心规则**
- 循环左移：最高位移出后补到最低位
- 循环右移：最低位移出后补到最高位
- 数据位一位不丢，整体相当于首尾相接的环

**类比**
- 循环移位像转盘：转到哪都在桌面上，转满一圈回到原位
- 逻辑/算术移位像传送带：移出的位直接掉出去，找不回来

**易错**
- 循环移位不进行乘除运算，只做位重排
- 循环移位没有“溢出”概念，所有位仍在
- 循环移位与逻辑/算术移位的区别是“移出位是否回来”

## 二、分类

**注**
- “不带 CF”指 CF 不参与循环环，但执行后 CF 仍会被移出的位更新
- “带 CF”指 CF 本身是环上的一节，相当于 $(w+1)$ 位循环

### 2.1 不带CF标志位的循环右移

![](../../images/Pasted%20image%2020260829185159.png)

- 最低位移到最高位，同时复制一份到 CF
- CF 不在环上，只记录移出位

### 2.2 不带CF标志位的循环左移

![](../../images/Pasted%20image%2020260829185239.png)

- 最高位移到最低位，同时复制一份到 CF
- CF 不参与循环

### 2.3 带CF标志位的循环右移

![](../../images/Pasted%20image%2020260829185321.png)

- 最低位移入 CF，CF 旧值移到最高位
- CF 与数据位构成 $(w+1)$ 位环

### 2.4 带CF标志位的循环左移

![](../../images/Pasted%20image%2020260829185352.png)

- 最高位移入 CF，CF 旧值移到最低位
- CF 与数据位构成 $(w+1)$ 位环

**易错**
- 不带 CF 的循环移位仍会更新 CF，只是 CF 不参与环
- 带 CF 的循环移位中，CF 是“环上的一节”，不是旁观者
- 循环左移 $n$ 位等价于循环右移 $w-n$ 位，逻辑/算术移位没有这种对称性

## 三、循环移位的应用

### 3.1 高低字节互换（大小端转换）

大端与小端存储的数据互转，本质是高字节与低字节对调——16 位数据循环左移 8 位的效果

例：`0x1234` 循环左移 8 位 → `0x3412`

### 3.2 多字长数据的整体移位

**问题**：32 位以上的大数拆到多个寄存器，移位时位如何在寄存器之间流动

**解法**
1. 低位寄存器逻辑左移 1 位，最高位进入 CF
2. 高位寄存器带 CF 循环左移 1 位，CF 旧值补入最低位

**易错**
- 低位寄存器必须用逻辑左移，把位“送出去”
- 高位寄存器必须用带 CF 循环左移，把 CF“接进来”
- 若低位也用不带 CF 的循环左移，最高位会绕回自己的最低位，位就串错门

### 3.3 逐位检测且不破坏原数

- 循环移位转满一圈后数据恢复原值
- 适合逐位检查、位扫描、统计 1 的个数

**短例（C 语言）**

```c
uint32_t rotl(uint32_t x, unsigned n) {
    n %= 32;
    return n ? (x << n) | (x >> (32 - n)) : x;
}
```

**易错**
- C 语言没有原生循环移位，必须手动拼接
- 必须用无符号类型；有符号右移可能补符号位，污染拼接结果
- 移位量必须先规约，避免移位数 ≥ 位宽

## 四、易混点速查

| 对比项 | 逻辑/算术移位 | 循环移位 |
| --- | --- | --- |
| 移出的位 | 直接丢弃 | 补到另一端，一位不丢 |
| 算术意义 | 左移乘 2、右移除 2 | 位重排，无乘除意义 |
| 溢出 | 算术左移可能溢出 | 无溢出概念，位都在 |
| 典型应用 | 算术运算、位掩码 | 格式转换、多字长移位、逐位检测 |

| 对比项 | 不带 CF 循环移位 | 带 CF 循环移位 |
| --- | --- | --- |
| CF 是否在环上 | 不在环上，但会被移出位更新 | 在环上，构成 $(w+1)$ 位环 |
| 移出位去向 | 补到另一端，同时复制到 CF | 进入 CF，CF 旧值补到另一端 |
| 典型用途 | 单寄存器位重排、字节交换 | 多寄存器串联的大数移位 |
