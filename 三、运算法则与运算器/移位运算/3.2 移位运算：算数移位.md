# 3.2 移位运算：算数移位

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.2）｜重要度 ★★★★★｜常见考法：选择题（算术左/右移、补码移位、符号位处理、溢出与精度）

**一句话核心**：算术移位把操作数当有符号数；右移补符号位，左移低位补 0，符号位是否变化取决于是否溢出

## 一、算数移位规则

![](../../images/Pasted%20image%2020260829183811.png)

| 操作 | 空位补什么 | 符号位 | 数学意义 |
| --- | --- | --- | --- |
| 算术左移 | 低位补 0 | 可能改变（溢出） | 乘以 2 |
| 算术右移 | 高位补符号位 | 保持不变 | 除以 2，向下取整 |

**提炼**
- 算术右移保持符号不变：正数补 0，负数补 1
- 算术左移低位补 0；若符号位被改变，说明溢出
- 算术右移对负数是“向下取整”，不是“向 0 取整”

**例**：4 位补码 `0101`（+5）
- 左移 1 位：`1010`（-6，溢出）
- 右移 1 位：`0010`（+2）

### 2.2 负数的算数移位

![](../../images/Pasted%20image%2020260829184330.png)

**例**：4 位补码 `1011`（-5）
- 算术右移 1 位：`1101`（-3），不是 -2
- 算术左移 1 位：`0110`（+6，溢出）

**易错**
- 负数右移不是“绝对值除以 2 再取负”；补码右移是向下取整
- `-5 >> 1 = -3`，不是 `-2`
- 算术左移可能把符号位从 0 变 1，或从 1 变 0，都是溢出

### 2.3 总结

![](../../images/Pasted%20image%2020260829184356.png)

| 数 | 算术左移 | 算术右移 |
| --- | --- | --- |
| 正数 | 低位补 0，可能溢出 | 高位补 0 |
| 负数 | 低位补 0，可能溢出 | 高位补 1 |
| 符号位 | 可能改变 | 保持不变 |

## 三、补码算术移位的另一种写法：符号位也参与移位

### 3.1 左移

![](../../images/Pasted%20image%2020260829184558.png)

- 符号位参与左移，低位补 0
- 若移位后符号位与原来不同，说明溢出
- 这种写法把符号位当作普通数据位，便于硬件统一处理

### 3.2 右移

![](../../images/Pasted%20image%2020260829184638.png)

- 符号位参与右移，高位补符号位
- 负数右移会丢失低位精度
- 右移不会改变符号位

### 3.3 优点

![](../../images/Pasted%20image%2020260829184800.png)

- 符号位与数值位用同一套移位通路，硬件简单
- 只需在移位后检查符号位是否变化，即可判断左移溢出

**易错**
- 408 常规口径：算术右移“符号位不变、高位补符号位”；“符号位参与移位”是同一操作的另一种描述，不要理解成“符号位可以被移走”
- 左移溢出判断看符号位是否变化；右移只丢精度，不溢出

## 四、C语言中的移位运算

![](../../images/Pasted%20image%2020260829184918.png)

**要点**
- 无符号数右移是逻辑右移，高位补 0
- 有符号数右移在 C 标准中是“实现定义”，常见编译器按算术右移处理
- 有符号数左移若溢出，C 标准规定为未定义行为
- 408 按“算术移位”的数学规则做题，不受 C 语言实现差异影响

**易错**
- 不要用 C 语言的有符号溢出行为反推 408 规则
- 移位位数不能超过字长；C 中移位位数 ≥ 位宽是未定义行为
