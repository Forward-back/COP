# 3.1 移位运算：逻辑移位

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.1）｜重要度 ★★★★｜常见考法：选择题（逻辑左/右移、补 0 规则、移位与乘除、与算术移位区别）

**一句话核心**：逻辑移位只移位、不认符号；左移低位补 0，右移高位补 0，移出的位直接丢弃

## 一、逻辑移位规则

![](../../images/Pasted%20image%2020260829182423.png)

| 操作 | 规则 | 位变化 | 数学意义（无符号） |
| --- | --- | --- | --- |
| 逻辑左移 | 低位补 0，高位丢弃 | 所有位左移 1 位 | 乘以 2 |
| 逻辑右移 | 高位补 0，低位丢弃 | 所有位右移 1 位 | 除以 2（向下取整） |

**提炼**
- 逻辑移位把操作数当作“纯位串”，不区分符号
- 左移 $n$ 位等价于乘以 $2^n$（无符号，且不溢出）
- 右移 $n$ 位等价于除以 $2^n$（无符号，向下取整）
- 移出的位进入 CF（若指令影响标志位），但不再回到数据中

**易错**
- 逻辑右移高位补 0，负数会变成正数；有符号数应使用算术右移
- 逻辑左移与算术左移的位操作相同，都是低位补 0
- 移位次数超过字长时，不同架构行为不同；408 按题目给出的位数计算
- 逻辑移位没有“符号位不变”的约定

### 2.1 位掩码

**清零某位**

![](../../images/Pasted%20image%2020260829183431.png)

**置 1 某位**

![](../../images/Pasted%20image%2020260829183518.png)

**提炼**
- 清零第 $n$ 位：与 `~(1 << n)` 相与
- 置 1 第 $n$ 位：与 `1 << n` 相或
- 取反第 $n$ 位：与 `1 << n` 异或
- 读取第 $n$ 位：右移 $n$ 位后与 1 相与

**短例（C 语言）**

```c
reg &= ~(1 << n);   // 清零第 n 位
reg |=  (1 << n);   // 置 1 第 n 位
```

**易错**
- `~` 会翻转高位，赋值给固定宽度类型时会截断；必要时显式掩码
- 位编号从 0 开始，最低位是第 0 位
- 位掩码是“按位操作”，不是逻辑与/或

**拓展**
- 位掩码还常用于提取字段、批量清零、权限位管理；408 只需掌握“与清零、或置 1、异或取反”三种基本操作
