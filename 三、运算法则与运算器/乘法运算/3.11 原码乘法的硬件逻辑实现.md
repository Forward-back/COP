# 3.11 原码乘法的硬件逻辑实现

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.11）｜重要度 ★★★★｜常见考法：选择题（符号位处理、数值位乘法、与原码/补码关系）

**一句话核心**：原码乘法把符号与数值分开：符号位异或，数值位按无符号乘法算

## 一、分析

原码乘法可基于 [[3.10 无符号数乘法的硬件逻辑实现]] 的逻辑实现，只需多处理一位符号位

**符号处理**
- 结果符号 $=x_s\oplus y_s$
- 数值位 $=|x|\times|y|$
- 符号位不参与数值乘法

***运算推导***

![](../../images/Pasted%20image%2020260904184859.png)

**提炼**
- 原码表示下，符号位与数值位独立
- 乘法规则：符号异或，绝对值相乘
- 结果原码 = 结果符号 + 数值乘积

**易错**
- 原码乘法的数值位是无符号乘法，不要按补码算
- 符号位异或后要放回结果最高位
- 0 的符号要单独处理；原码有 +0 和 -0

## 二、硬件逻辑实现

![](../../images/Pasted%20image%2020260904185043.png)

**结构**
- 符号位异或门产生结果符号
- 数值位送入无符号乘法器
- 乘积数值位与符号位拼接成原码结果

***过程***

![](../../images/Pasted%20image%2020260904185240.png)

**步骤**
1. 取出两个操作数的符号位，异或得到结果符号
2. 取绝对值，送入无符号乘法器
3. 数值位相乘，得到 $2n$ 位乘积
4. 拼接符号位，得到原码结果

**易错**
- 绝对值运算不是“取反加 1”；原码的数值位直接取，符号位单独处理
- 结果位数是 $2n$ 位（数值位）+ 1 位符号
- 原码乘法不适合直接用于补码数据；补码要用 Booth 算法

## 三、总结

![](../../images/Pasted%20image%2020260904185258.png)

| 项目 | 原码乘法 |
| --- | --- |
| 符号 | 异或 |
| 数值 | 无符号乘法 |
| 结果 | 原码 |
| 硬件 | 符号异或 + 无符号乘法器 |
| 适用 | 原码表示的数据 |

**易错**
- 原码乘法与补码乘法不能混用
- 符号位不参与数值运算，但结果符号必须单独产生
- 绝对值相乘可能产生 $2n$ 位结果，不能截断

**知识关联**：无符号乘法（[[3.10 无符号数乘法的硬件逻辑实现]]）；Booth 算法（[[3.12 补码乘法的硬件逻辑实现——Booth算法]]）；原码表示（第 2 章）
