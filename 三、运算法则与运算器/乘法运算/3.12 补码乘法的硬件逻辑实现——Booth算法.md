# 3.12 补码乘法的硬件逻辑实现——Booth算法

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.12）｜重要度 ★★★★★｜常见考法：大题（Booth 重编码、加减选择、算术右移、结果符号）

**一句话核心**：Booth 算法把补码乘法转成“看乘数相邻两位，决定加/减被乘数，再算术右移”

**提炼**
- 补码乘法不能像原码那样“符号与数值分开”
- 把乘数按补码展开，利用 $2^k$ 的权重合并项
- 合并后出现“相邻两位之差”，这就是 Booth 重编码的来源

**Booth 重编码表**

| $Q_i$ | $Q_{i-1}$ | 操作 |
| :-: | :-: | --- |
| 0 | 0 | 不加不减 |
| 0 | 1 | 加 $M$ |
| 1 | 0 | 减 $M$ |
| 1 | 1 | 不加不减 |

- $Q_i$ 是当前位，$Q_{i-1}$ 是低位（初始为 0）
- “减 $M$”用加 $[-M]_补$ 实现
- 每步操作后算术右移

**易错**
- 重编码看的是“当前位与低位”，不是“当前位与高位”
- 10 是减，01 是加，不要记反
- 初始 $Q_{-1}=0$，不是 1

## 三、Booth算法的硬件逻辑实现

![](../../images/Pasted%20image%2020260904190715.png)

**部件**
- $M$：被乘数
- $Q$：乘数
- $Q_{-1}$：乘数最低位的前一位，初始 0
- $A$：部分积，初始 0
- 计数器：循环 $n$ 次

**流程**
1. 根据 $Q_0Q_{-1}$ 查表，决定 $A\leftarrow A+M$、$A\leftarrow A-M$ 或不变
2. $A,Q,Q_{-1}$ 联合算术右移 1 位
3. 计数器减 1，不为 0 则重复
4. 结束后 $A,Q$ 拼接为乘积

**注**：采用双符号位，双符号位见 [[3.5 定点数的加减运算——溢出检测]]

![](../../images/Pasted%20image%2020260904190528.png)

**易错**
- 算术右移时符号位不变，$A$ 的最高位补符号位
- $Q$ 的最低位进入 $Q_{-1}$，$A$ 的最低位进入 $Q$ 的最高位
- 双符号位用于容纳中间结果，防止溢出
- Booth 算法对正负乘数都适用，不需要先转原码

## 四、Booth算法执行示例

![](../../images/Pasted%20image%2020260904190643.png)

**执行要点**
1. 写出 $[M]_补$、$[-M]_补$
2. $A=0$，$Q$ 装乘数，$Q_{-1}=0$
3. 逐拍查表、加减、算术右移
4. 最后 $A,Q$ 拼接为 $2n$ 位乘积

**易错**
- 加减后不要忘记右移
- 右移是算术右移，不是逻辑右移
- 结果的符号由补码自然产生，不需要单独异或
- 循环次数等于乘数位数 $n$
