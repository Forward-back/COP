# 3.20 浮点运算——乘法

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.20）｜重要度 ★★★★｜常见考法：选择题/大题（阶码相加、尾数相乘、规格化、舍入、溢出）

**一句话核心**：浮点乘法 = 阶码相加 + 尾数相乘 + 规格化 + 舍入；符号位单独异或

![](../../images/Pasted%20image%2020260909171000.png)

## 一、运算步骤

**1. 符号位**
- 结果符号 $=S_x\oplus S_y$

**2. 阶码相加**
- 补码/一般浮点：$E=E_x+E_y$
- IEEE 754：$E=E_x+E_y-\text{bias}$（因为两个阶码都带了偏置，相加多算了一次）

**3. 尾数相乘**
- 尾数按定点小数相乘
- 结果尾数范围通常在 $[1,4)$（IEEE 规格化尾数 $[1,2)$ 相乘）

**4. 规格化**
- 尾数 ≥ 2：右规，尾数右移 1 位，阶码加 1
- 尾数 < 1：左规，尾数左移，阶码减 1

**5. 舍入**
- 按题目要求 0 舍 1 入/恒置 1/就近舍入
- 舍入后可能再次非规格化，需要再规格化

**6. 溢出判断**
- 阶码上溢：结果太大
- 阶码下溢：结果太小，可能变为 0 或非规格化数

## 二、模板

1. 拆符号、阶码、尾数，补隐藏位
2. 符号异或
3. 阶码相加，IEEE 要减偏置
4. 尾数相乘
5. 规格化
6. 舍入
7. 阶码加偏置写回，判断溢出

**易错**
- IEEE 阶码相加后要减一次偏置，不能直接相加
- 尾数相乘结果可能 ≥ 2，必须右规
- 符号位不参与数值乘法
- 舍入后可能再次规格化
