# 3.21 浮点运算——除法

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.21）｜重要度 ★★★★｜常见考法：选择题/大题（阶码相减、尾数相除、规格化、舍入、除零）

**一句话核心**：浮点除法 = 阶码相减 + 尾数相除 + 规格化 + 舍入；符号位单独异或，除数不能为 0

![](../../images/Pasted%20image%2020260909171127.png)

## 一、运算步骤

**1. 符号位**
- 结果符号 $=S_x\oplus S_y$

**2. 阶码相减**
- 一般浮点：$E=E_x-E_y$
- IEEE 754：$E=E_x-E_y+\text{bias}$（减完后要补回偏置）

**3. 尾数相除**
- 尾数按定点小数相除
- 商尾数范围通常在 $[0.5,2)$，需要规格化

**4. 规格化**
- 尾数 < 1：左规，尾数左移，阶码减 1
- 尾数 ≥ 2：右规，尾数右移，阶码加 1

**5. 舍入**
- 按题目要求舍入
- 舍入后可能再次非规格化

**6. 溢出与异常**
- 阶码上溢/下溢
- 除数为 0：结果为 ∞ 或触发除零异常
- 0/0、∞/∞：NaN

## 二、模板

1. 拆符号、阶码、尾数，补隐藏位
2. 符号异或
3. 阶码相减，IEEE 要加偏置
4. 尾数相除
5. 规格化
6. 舍入
7. 阶码加偏置写回，判断溢出/除零

**易错**
- IEEE 阶码相减后要加一次偏置，不能直接写回
- 尾数相除的商可能 < 1，必须左规
- 除数不能为 0
- 符号位不参与数值除法
