# 3.8 串行进位加法器的硬件逻辑实现

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.8）｜重要度 ★★★★★｜常见考法：选择题/大题（进位链、延迟、溢出、加减法共用、控制信号）

**一句话核心**：$n$ 个全加器串联，低位进位逐级传高位；结构简单但延迟随位数线性增加

## 一、构建方式

![](../../images/Pasted%20image%2020260901185709.png)

**结构**
- $n$ 个一位全加器串联
- 第 $i$ 位的 $C_o$ 接第 $i+1$ 位的 $C_i$
- 最低位 $C_0$ 接初始进位
- 最高位 $C_n$ 作为最终进位/溢出标志

**延迟**
- 每一位的进位要等低位算完
- $n$ 位加法器延迟约为 $n$ 级进位延迟
- 结构简单、面积小，但位数多时速度慢

**易错**
- 串行进位不是“串行加法器”；它仍是并行输入，只是进位串行
- 延迟主要由进位链决定，不是异或门
- 最低位 $C_0$ 必须明确接 0 或控制信号

## 二、溢出检测

1. 对于无符号数：最高位的进位即为检测指标
2. 对于有符号数
   - 法一：对比操作数与结果的符号位
   - 法二：对比符号位的进位与最高数值位的进位

**注**
- 无符号数只需检测最后的进位 $C_n$
- 有符号数用 $OF=C_n\oplus C_{n-1}$

***考虑将符号位进位、最高数值位进位连接到同一异或门***

![](../../images/Pasted%20image%2020260901190355.png)

**提炼**
- 无符号溢出：$C_n=1$
- 有符号溢出：$C_n\ne C_{n-1}$
- 两者不是同一个标志，题目问“溢出”要先看数据解释

## 三、加减法共用

对于补码减法，可以转化成加法；需要求减数的相反数补码：所有位取反，末位加 1

**控制信号 $Sub$**
- $Sub=0$：加法，$B$ 不变，$C_0=0$
- $Sub=1$：减法，$B$ 各位取反，$C_0=1$

**实现**
- 每个 $B_i$ 先与 $Sub$ 异或：$B_i'=B_i\oplus Sub$
- 最低位进位 $C_0=Sub$
- 结果：$A+B'+Sub=A+B+\overline{B}+1$（减法）

![](../../images/Pasted%20image%2020260901191107.png)

![](../../images/Pasted%20image%2020260901191121.png)

**易错**
- 减法不是“直接减”，而是“取反加 1”
- $Sub$ 同时控制“取反”和“最低位加 1”，不能只做一半
- 符号位也参与取反和加法

***问题3、4***

**考什么**：进位链延迟、溢出判断、加减共用控制
**常见错因**
- 把无符号进位当有符号溢出
- 减法忘记最低位加 1
- 延迟只算一级全加器

**解题模板**
1. 确定位数与初始进位
2. 逐位算 $S_i$、$C_{i+1}$
3. 无符号看 $C_n$；有符号看 $C_n\oplus C_{n-1}$
4. 减法：$B$ 取反，$C_0=1$
5. 延迟按进位链级数估算
