# 3.6 定点数的加减运算——逻辑代数与逻辑门

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.6）｜重要度 ★★★★｜常见考法：选择题（基本门、复合门、布尔代数化简、德摩根定律、加法器电路）

**一句话核心**：逻辑门是加法器的积木；与/或/非是基本门，与非/或非是万能门，异或用于求和与比较

## 一、概述

![](../../images/Pasted%20image%2020260901144446.png)

**提炼**
- 逻辑代数是二值代数：变量只取 0/1
- 逻辑门实现基本逻辑运算，组合门实现复合运算
- 加法器、比较器、ALU 都由逻辑门组合而成

![](../../images/Pasted%20image%2020260901145554.png)

### 3.4 同或运算、同或门

![](../../images/Pasted%20image%2020260901145820.png)

- $Y=\overline{A\oplus B}=AB+\overline{A}\overline{B}$：相同为 1，不同为 0
- 用途：相等比较、同或校验

**易错**
- 异或不是万能门；不能用异或单独构建与/或/非
- 异或的“或”是“排他或”，两个 1 得 0
- 同或与异或互为取反

## 四、逻辑代数运算法则

| 定律 | 与形式 | 或形式 |
| --- | --- | --- |
| 交换律 | $A\cdot B=B\cdot A$ | $A+B=B+A$ |
| 结合律 | $(A\cdot B)\cdot C=A\cdot(B\cdot C)$ | $(A+B)+C=A+(B+C)$ |
| 分配律 | $A\cdot(B+C)=AB+AC$ | $A+BC=(A+B)(A+C)$ |
| 幂等律 | $A\cdot A=A$ | $A+A=A$ |
| 互补律 | $A\cdot\overline{A}=0$ | $A+\overline{A}=1$ |
| 0-1 律 | $A\cdot0=0,\ A\cdot1=A$ | $A+0=A,\ A+1=1$ |
| 吸收律 | $A+AB=A$ | $A(A+B)=A$ |
| 双重否定 | $\overline{\overline{A}}=A$ | — |
| 德摩根 | $\overline{AB}=\overline{A}+\overline{B}$ | $\overline{A+B}=\overline{A}\cdot\overline{B}$ |
| 冗余律 | $AB+\overline{A}C+BC=AB+\overline{A}C$ | $(A+B)(\overline{A}+C)(B+C)=(A+B)(\overline{A}+C)$ |

**提炼**
- 德摩根定律是“与的非 = 非的或，或的非 = 非的与”
- 冗余律用于消去多余项
- 对偶规则：与↔或、0↔1，等式仍成立

**易错**
- 分配律的或对与形式 $A+BC=(A+B)(A+C)$ 容易漏
- 德摩根定律要把“整体非”分配到每个变量，并改变运算符号
- 逻辑化简不是算术化简，不能约分
