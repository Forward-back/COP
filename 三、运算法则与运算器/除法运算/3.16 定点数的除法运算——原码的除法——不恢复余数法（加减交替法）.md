# 3.16 定点数的除法运算——原码的除法——不恢复余数法（加减交替法）

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.16）｜重要度 ★★★★★｜常见考法：大题（加减交替规则、上商、余数修正、与原码除法关系）

**一句话核心**：余数为负时不加回除数，而是下一步改“减”为“加”；这就是加减交替法

## 一、针对恢复余数过程的改进

***当 $R_i$ 为负数时，我们需要恢复余数，数学表达式如下***

![](../../images/Pasted%20image%2020260907163245.png)

**推导**
- 恢复余数：$R_i+Y$
- 下一步左移后再减 $Y$：$2(R_i+Y)-Y=2R_i+Y$
- 所以，余数为负时，不必恢复，直接左移后加 $Y$

**规则**
- $R_i\ge0$：商 1，下一步减 $Y$
- $R_i<0$：商 0，下一步加 $Y$
- 每步先左移，再按上一步余数符号选择加/减
- 最后若余数为负，需要修正（加回 $Y$）

**易错**
- “加减交替”不是随意交替，而是由余数符号决定
- 余数为负时商 0，但下一步不是继续减，而是加
- 最后余数可能为负，需要恢复；商也可能需要修正

## 二、举例

![](../../images/Pasted%20image%2020260907164028.png)

**步骤**
1. 初始化余数、商
2. 左移余数
3. 根据上一步余数符号选择 $+Y$ 或 $-Y$
4. 根据新余数符号上商
5. 重复 $n$ 次
6. 若最后余数为负，加 $Y$ 修正

**易错**
- 上商依据是“本步运算后的余数符号”，不是“上一步”
- 左移发生在加减之前
- 原码除法的商符仍由两数符号异或得到
- 余数符号应与被除数一致；不一致时需修正
