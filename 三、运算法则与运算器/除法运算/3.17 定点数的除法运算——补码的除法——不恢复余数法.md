# 3.17 定点数的除法运算——补码的除法——不恢复余数法

**考纲定位**：计算机组成原理 · 第 3 章 运算方法（3.17）｜重要度 ★★★★★｜常见考法：大题（商符、上商规则、加减交替、余数修正、小数/整数模板）

**一句话核心**：补码除法把符号位并入运算；第一拍定商符，之后按“余数与除数同号商 1、异号商 0”逐位上商，最后恒置 1 并修正余数

## 一、如何确定商值

![](../../images/Pasted%20image%2020260907181204.png)

**上商规则**
- 余数与除数同号：商 1
- 余数与除数异号：商 0
- 本步商决定下一步加还是减：商 1 下一步减除数，商 0 下一步加除数

**注释**
- $X,Y$ 同号：差与 $Y$ 异号，说明减 $Y$ 使 $X$ 逆转，$|Y|$ 更大，不够减
- $X,Y$ 异号：差与 $Y$ 同号，说明 $Y$ 对 $X$ 的削弱超过 $X$ 本身，$|Y|$ 更大，不够减

**易错**
- 上商看“余数与除数”的符号关系，不是“余数与被除数”
- 商 1 表示“够减”，商 0 表示“不够减”
- 补码除法的第一位商就是商符，不是最后单独拼接

## 二、如何确定商符

![](../../images/Pasted%20image%2020260907182505.png)

**规则**
- 补码除法：第一拍上商即商符
- 原码除法：商符由两数符号异或得到
- 小数除法前提：$|x|<|y|$，否则商 ≥ 1 溢出

**注**：不可误以为定点整数的除法没有溢出现象，只是定点小数溢出比较特殊

**定点整数除法的溢出**
- 被除数双字长 $2n$ 位，除数单字长 $n$ 位，商/余数单字长 $n$ 位
- 若被除数高 $n$ 位的绝对值 ≥ 除数绝对值，商的有效位数超过 $n$ 位，溢出
- 例：8 位除数除 16 位被除数，高 8 位已大于除数，商至少 9 位，8 位放不下

**易错**
- 小数除法要求 $|x|<|y|$；整数除法看商是否超范围
- 补码除法的商符由第一拍产生，不是最后异或
- 溢出与“余数是否为负”不是一回事

## 三、如何确定新余数

![](../../images/Pasted%20image%2020260907190333.png)

**加减交替规则**
- 余数与除数同号：下一步减除数
- 余数与除数异号：下一步加除数
- 每步先左移余数，再按上一步商选择加/减

**公式化**
- 设 $R_i$ 为第 $i$ 步余数，$Y$ 为除数
- $R_i$ 与 $Y$ 同号：$R_{i+1}=2R_i-Y$，商 1
- $R_i$ 与 $Y$ 异号：$R_{i+1}=2R_i+Y$，商 0
- 最后若末位商为 0，余数加 $Y$ 修正（使余数符号与被除数一致）

**易错**
- 左移发生在加减之前
- 加减选择看“上一步商”，不是“本步新余数”
- 末位商为 0 时，余数需加 $Y$ 修正
- 商为负时，余数符号应与被除数一致

## 四、统一五步内核

1. 求 $[Y]_补$、$[-Y]_补$；余数 $R$ 建议用双符号位
2. 装数
   - 小数：$R=[X]_补$，$Q=0$
   - 整数：$R$ 装符号扩展高位，$Q$ 装被除数低 $n$ 位，$R\|Q$ 才是被除数
3. 第一拍不移位：$X,Y$ 同号减 $Y$，异号加 $Y$；根据新余数与 $Y$ 的符号上商符
4. 重复 $n$ 轮：$R,Q$ 联合左移 1 位 → 按上一步商选择加/减 $Y$ → 根据新余数与 $Y$ 的符号上商
5. 收尾：末位恒置 1；若要求精确余数且末位商为 0，则 $R+Y$ 修正

**小数模板**
- $R$ 装被除数，$Q$ 清零
- 第一拍定商符
- $n$ 轮左移、加减、上商
- 真余数按小数点位置解释，通常为 $R\times2^{-n}$

**整数模板**
- 被除数符号扩展为 $2n$ 位，拆成 $R\|Q$
- $Q$ 不能清零；清零等于改变了被除数
- $n$ 轮后 $Q$ 的 $n+1$ 位（含商符）为商
- 末位商 0 时，余数需加 $Y$ 修正

**易错**
- 小数题把 $X$ 拆进 $Q$：没有高位段可落，商没有来源
- 整数题 $Q$ 清零：联合寄存器不等于被除数，商符错、中间溢出
- 忘记第一拍不移位：商符错位，全表报废
- 按当次商而不是上一步商选加减：后面全错
- 5 位结果直接写、没丢第 6 位进位：补码按模运算，必须丢弃

## 五、示例

![](../../images/Pasted%20image%2020260907190751.png)

**考场检查**
1. 商符是否由第一拍产生
2. 每轮是否先左移再加减
3. 加减是否由上一步商决定
4. 末位是否恒置 1
5. 余数是否需要修正
6. 验算：$q\times y+r=x$，$|r|<|y|$，$r$ 与 $x$ 同号或为 0

**拓展：Q 为什么要多一级**
- 硬件中 $Q$ 通常是 $n+1$ 级移位寄存器，第一拍商符写入最低级，随移位走到最高位
- 教科书画 $n$ 格只是排版简化；若按 $n$ 格理解，就会觉得商符“无处可写”
- 408 只需掌握“第一拍上商符、最后商在 Q 中”的结论，不考具体触发器级数
