# 7.9 常用总线

**考纲定位**：计算机组成原理 · 第 7 章 总线（7.9）｜重要度 ★★｜常见考法：选择题（总线分类、英文缩写识别、USB/PCIe 特性）

**一句话核心**：常用总线按位置分为片内、系统、I/O、外部四类；考试重点是识别缩写并归入正确类别

## 一、常用总线总览

![](../images/Pasted%20image%2020261022115756.png)

| 类别 | 典型标准 |
|---|---|
| 片内总线 | AMBA、Wishbone |
| 系统总线 | ISA/EISA、MCA、VESA、PCI、FSB、IHA（HI）、HT、QPI、DMI |
| I/O 总线 | AGP、PCIe、LPC、SPI、I2C/SMBus、ATA/IDE、SATA、SCSI、SAS、Fiber Channel |
| 外部总线（通信总线） | RS-232-C、RS-485、IEEE-488、USB、IEEE 1394、Thunderbolt、InfiniBand |

- 分类不是绝对的：同一标准在不同教材/时代可能被归入不同类别，408 以“连接对象 + 位置”判断
- 考试常把总线缩写与显示器、性能指标、存储器等缩写混在一起考

## 二、系统总线

![](../images/Pasted%20image%2020261022115917.png)

- 系统总线（地址总线、数据总线、控制总线）是连接 CPU、主存、I/O 模块等主要功能部件的“信息主干道”，与 CPU 引脚直接相连
- 随着总线架构的演进，系统总线也被称为主机总线、CPU 总线、前端总线 FSB（Front Side Bus）
- 作为 CPU 与其他功能部件进行数据交换的“信息主干道”，系统总线通常采用同步传输方式
- 早期系统总线一般采用并行传输总线；最新的高速系统总线多采用串行传输总线
- 典型标准：ISA/EISA、MCA、VESA、PCI、FSB、HT、QPI、DMI

## 三、I/O 总线

![](../images/Pasted%20image%2020261022120014.png)

- I/O 总线是计算机系统中连接各类中低速 I/O 设备的重要通道
- I/O 总线通过专用桥接芯片与高速总线相连，实现了低速设备与高速总线的分离，从而有效提升总线系统的整体性能
- 随着计算机系统性能的飞速发展，早期的系统总线（如 ISA/EISA）已演变成 I/O 总线
- 典型标准：AGP、PCIe、LPC、SPI、I2C/SMBus、ATA/IDE、SATA、SCSI、SAS、Fiber Channel
- 注意：PCIe 在现代计算机中既承担 I/O 设备连接，也常作为系统互连，分类时看题目语境

## 四、外部总线

![](../images/Pasted%20image%2020261022120046.png)

- 外部总线（一般指通信总线）用于实现计算机与外部系统或独立设备（如控制仪表、测试仪器、其他计算机等，而非标准 I/O 设备）之间的数据通信
- 由于外部总线所连接系统或设备的特性（连接方式、传输速率、传输距离、工作方式等）千差万别，外部总线种类繁多
- 典型标准：RS-232-C、RS-485、IEEE-488、USB、IEEE 1394、eSATA、Thunderbolt、InfiniBand
- 相对于外部总线，系统总线和 I/O 总线也可以称为内部总线

## 五、片内总线

![](../images/Pasted%20image%2020261022120117.png)

![](../images/Pasted%20image%2020261022120135.png)

- 片内总线位于芯片内部，连接 CPU 内部的寄存器、ALU、缓存，或 SoC 中的各 IP 核
- AMBA（ARM 标准）
  - AHB：高性能总线，支持高频率、高带宽的系统骨干
  - ASB：第一代 AMBA 系统总线，比 AHB 数据位宽小
  - APB：外设总线，通过桥接器挂接于 AHB/ASB 之下的二级总线，专为中低速外设设计
  - AXI：AMBA 4.0 扩展版，现代实现多核 SoC 接口，提供高带宽与低延迟通信
- Wishbone
  - 开源标准，逻辑简单、完全免费，适合 FPGA/开源芯片
  - 灵活互连结构、设计简单、完全免费开放
- 片内总线的价值：SoC 中 IP 核可复用，降低芯片设计复杂度

## 六、例题

![](../images/Pasted%20image%2020261022120238.png)

**2010 题 20**：下列选项中的英文缩写词均为总线标准的是（D）

- A. PCI、CRT、USB、EISA：CRT 是阴极射线管显示器，不是总线
- B. ISA、CPI、VESA、EISA：CPI 是每条指令周期数，性能指标，不是总线
- C. ISA、SCSI、RAM、MIPS：RAM 是存储器，MIPS 是性能指标/处理器架构，不是总线
- D. ISA、EISA、PCI、PCI-Express：全部是总线标准

解析关键：先识别哪个缩写不是总线，再用排除法

![](../images/Pasted%20image%2020261022120328.png)

**2012 题 26**：下列关于 USB 总线特性的描述中，错误的是（D）

- A. 可实现外设的即插即用和热拔插：正确
- B. 可通过级联方式连接多台外设：正确，USB 通过 Hub 级联
- C. 是一种通信总线，连接不同外设：正确
- D. 同时可传输 2 位数据，数据传输率高：错误，USB 是串行总线，逐位传输，不是 2 位并行

解析关键：USB 是串行通信总线，不是并行；高速来自高工作频率、差分传输与编码，不是“同时传 2 位”

## 七、易错辨析

| 易混点 | 核心区分 |
|---|---|
| 系统总线 vs I/O 总线 | 系统总线连 CPU/主存等主干部件；I/O 总线连中低速外设 |
| I/O 总线 vs 外部总线 | I/O 总线连标准外设；外部总线（通信总线）连外部系统/独立设备，如仪器、其他计算机 |
| 片内总线 vs 系统总线 | 片内总线在芯片内部连 IP 核；系统总线在芯片之间/板级连主要部件 |
| USB 是串行还是并行 | 串行；不是 2 位并行 |
| PCIe 是总线还是互连 | 点对点串行互连；在 408 中常归入 I/O/系统互连，按题目语境 |
| AMBA 属于哪类 | 片内总线（SoC 内部互连） |
| RS-232-C 属于哪类 | 外部总线/通信总线，不是系统总线 |

## 八、考法透视

**常见题型**

- 给缩写，判断是否为总线标准、属于哪一类
- 给连接对象，判断应选系统/I/O/外部/片内总线
- 判断 USB、PCIe 的串行/并行、热插拔、级联特性
- 给 SoC 场景，选择 AMBA/Wishbone
- 结合 7.8 的结构，判断某总线位于哪一层

**常见设错点**

1. 把 CRT、CPI、RAM、MIPS 当成总线标准
2. 认为 USB 是并行总线
3. 认为 PCIe 是共享并行总线
4. 把 RS-232-C 当成系统总线
5. 把 AMBA 当成系统总线（实际是片内总线）
6. 认为外部总线只能连接标准 I/O 设备（实际连外部系统/独立设备）
