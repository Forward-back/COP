# 7.4 总线传输过程与总线事务

**考纲定位**：计算机组成原理 · 第 7 章 总线（7.4）｜重要度 ★★★★｜常见考法：选择题（四个阶段、总线事务类型、突发传输 vs 普通传输）

**一句话核心**：一次总线传输按“申请 → 寻址 → 传输 → 结束”四阶段进行；总线事务是主从设备之间完成一次信息交换的过程，突发传输用一次寻址换多次传输

## 一、总线传输的四个阶段

![](../../images/Pasted%20image%2020261021172444.png)

| 阶段 | 主设备做什么 | 从设备/控制器做什么 |
|---|---|---|
| 申请（仲裁） | 向总线控制器发出总线请求 | 控制器收到一个或多个请求后，按仲裁规则决定下一个总线周期给谁 |
| 寻址 | 通过地址总线发出本次传输的地址（存储器地址或 I/O 端口地址）及读/写命令 | 从设备收到地址与命令后进行地址译码；被选中的从设备发出应答信号，准备传输 |
| 传输 | 写操作：数据从主设备送到从设备；读操作：数据从从设备送到主设备 | 从设备配合完成数据收发 |
| 结束 | 撤销总线请求，释放总线 | 撤销应答信号 |

- 一般情况下（非 DDR、非突发传输等），1 个总线周期只能传输 1 个总线宽度的数据
- 申请阶段解决“谁用总线”，寻址阶段解决“找哪个从设备、做什么操作”，传输阶段解决“数据怎么走”，结束阶段负责释放资源
- 没有申请阶段的总线（如单主设备系统）可以省略仲裁，但寻址、传输、结束仍然存在

## 二、总线事务

![](../../images/Pasted%20image%2020261021172545.png)

- 总线事务：总线上的一对主/从设备之间完成一次信息交换的过程
- 按操作性质划分的典型总线事务
  - 存储器读
  - 存储器写
  - I/O 读
  - I/O 写
  - 中断响应
  - DMA 响应
- 一般情况下，总线事务包括
  - 一个寻址阶段
  - 一个传输阶段（数据阶段）
- 注意区分
  - 总线传输过程：申请 → 寻址 → 传输 → 结束（四个阶段）
  - 总线事务：通常指寻址 + 传输（一次信息交换）；申请和结束是总线传输过程的外围阶段

## 三、普通传输 vs 突发传输

![](../../images/Pasted%20image%2020261021172631.png)

**普通传输模式**

- 一次寻址、一次传输
- 每传一个数据单元，都要重新给出一次地址
- 地址总线在每次传输前都要忙碌一次，地址开销大

**突发传输模式（Burst Mode）**

- 一次寻址、多次传输
- 主设备发送一段连续数据单元的首地址，随后连续传输多个数据
- 从设备按首地址递增，依次接收/发送数据
- 减少地址阶段的次数，提高总线利用率

![](../../images/Pasted%20image%2020261021172703.png)

| 模式 | 寻址次数 | 传输次数 | 地址开销 | 适用 |
|---|---|---|---|---|
| 普通传输 | 每个数据一次 | 一次 | 大 | 离散、随机访问 |
| 突发传输 | 一段数据一次 | 多次 | 小 | 连续数据块、内存读写、DMA |

- 突发传输的关键：地址只给一次，后续数据按连续地址递增
- 突发传输常与 DMA 配合：DMA 搬运连续数据块时，用突发传输减少地址开销
- 408 常考“突发传输为什么快”：减少寻址阶段，不是提高时钟频率

## 四、易错辨析

| 易混点 | 核心区分 |
|---|---|
| 总线传输过程 vs 总线事务 | 传输过程四阶段：申请、寻址、传输、结束；总线事务通常指寻址 + 传输的一次信息交换 |
| 申请 vs 仲裁 | 申请是主设备发出请求；仲裁是控制器/分布式逻辑决定谁获得使用权 |
| 寻址 vs 传输 | 寻址传地址和命令；传输传数据 |
| 普通传输 vs 突发传输 | 普通一次寻址一次传输；突发一次寻址多次传输 |
| 突发传输 vs DDR | 突发减少寻址次数；DDR 提高每时钟周期的传输次数，两者不是一回事 |
| 总线事务类型 | 存储器读/写、I/O 读/写、中断响应、DMA 响应，不是“中断请求” |
| 结束阶段 | 主设备撤销请求、释放总线；不是从设备释放总线 |

## 五、考法透视

**常见题型**

- 给总线传输流程图，补全四个阶段的顺序
- 判断某操作属于哪种总线事务（存储器读/写、I/O 读/写、中断响应、DMA 响应）
- 比较普通传输与突发传输的时序图
- 计算突发传输节省的地址阶段数/总线周期数
- 判断“总线事务包括哪两个阶段”

**常见设错点**

1. 把“总线事务”等同于“总线传输过程”四阶段
2. 认为突发传输每个数据都要给地址
3. 认为突发传输提高了时钟频率（实际是减少寻址开销）
4. 把 DDR 与突发传输混为一谈
5. 认为结束阶段是从设备释放总线
6. 认为所有总线都必须有申请/仲裁阶段（单主设备可省略）

## 七、费曼自测

1. 总线传输过程分哪四个阶段
   → 申请（仲裁）、寻址、传输、结束

2. 总线事务一般包括哪两个阶段
   → 寻址阶段、传输（数据）阶段

3. 普通传输和突发传输的区别是什么
   → 普通一次寻址一次传输；突发一次寻址多次传输，减少地址开销

4. 突发传输为什么能提高总线利用率
   → 多个数据只给一次首地址，省掉重复的寻址阶段

5. 总线事务有哪些典型类型
   → 存储器读/写、I/O 读/写、中断响应、DMA 响应
