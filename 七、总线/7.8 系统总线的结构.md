# 7.8 系统总线的结构

**考纲定位**：计算机组成原理 · 第 7 章 总线（7.8）｜重要度 ★★★★｜常见考法：选择题（单/双/三总线、高性能总线、桥接的作用）

**一句话核心**：系统总线结构从单总线 → 双总线 → 三总线 → 高性能分层总线；核心思路是分离高速与低速数据流

## 一、单总线结构

![](../images/Pasted%20image%2020261022115423.png)

- 所有部件（CPU、主存、I/O 接口、外设）都连接在同一组系统总线上
- 优点
  - 结构简单：所有部件通过单总线（多条并行线）连接，硬件设计复杂度低
  - 易于扩充设备：新设备可直接挂接到共享总线上
  - 成本较低：总线数量少，布线简单，制造成本低
  - 灵活性高：部件间的通信统一，管理逻辑相对简单
- 缺点
  - 带宽瓶颈：所有设备共享同一总线带宽，高速设备无法充分发挥性能
  - 通信冲突：所有设备争用同一总线，导致传输延迟增加
  - 系统性能受限：总线负载重时，整体效率下降，尤其在高并发场景下
  - 可靠性低：总线故障可能导致整个系统瘫痪
  - 扩展性受限：随着设备增多，总线竞争加剧，性能进一步恶化
- 典型：Intel 8086 到 80386 时代的 ISA、EISA、MCA 总线，都是典型的单总线结构

## 二、双总线结构

![](../images/Pasted%20image%2020261022115445.png)

有两种常见形态：

1. 将 CPU 与主存之间的高速访问从系统总线中分离出来
   - CPU 与主存之间用专门的存储总线（或主机总线）
   - 系统总线主要连接 I/O 接口与外设
2. 将慢速外设的通信通道从系统总线中分离出来
   - CPU、主存、芯片组挂在系统总线上
   - 慢速 I/O 设备通过桥接器挂到 I/O 总线上

**核心思想一致：将总线中的慢速数据传输与高速数据传输进行分离，减少速率差异对整体性能的影响**

- 优点：CPU 与主存之间的高带宽不被慢速 I/O 拖累；I/O 设备也不占用主存总线
- 缺点：需要额外的总线/桥接器，硬件复杂度增加

## 三、三总线结构

![](../images/Pasted%20image%2020261022115506.png)

- 相较于双总线结构，三总线结构将不同传输速率的数据传输进一步细分
- CPU、主存（DRAM）连接在系统总线上
- 显卡、磁盘、网卡等高速设备连接在 PCI 总线上
- 串口、并口、PS/2 键盘和鼠标等传统慢速设备连接在 ISA 总线上
- 通过 PCI-ISA 桥连接 PCI 总线与 ISA 总线；通过 PCI-PCI 桥扩展 PCI 总线，以支持更多 PCI 设备、提高 PCI 总线的负载能力
- 优点：不同速度设备各得其所，系统整体效率高
- 缺点：桥接器多、结构复杂、成本高
- 注意：这里的“三总线”是层次结构（系统总线 + PCI 总线 + ISA 总线），不是“数据总线、地址总线、控制总线”三类功能总线

## 四、高性能总线结构

![](../images/Pasted%20image%2020261022115537.png)

随着计算机技术与 CPU 性能的飞速进步，以及高速网络、视频图形等设备的涌现，传统的 PCI 总线已难以满足需求，从而催生了 AGP 图形加速总线、PCIe 等新一代总线。总线结构自身也向着高性能不断演化，其发展趋势可总结为以下几点：

- 采用分层的多总线结构，各层次总线之间通过桥接技术进行连接和缓冲
- 将处理器与 I/O 设备之间的活动，与 I/O 设备与主存之间的数据传输分离开来，提升效率
- 在布局上，让高速设备更靠近 CPU，而慢速设备则相对远离
- 桥接芯片高度集成，最终形成了经典的南北桥架构

![](../images/Pasted%20image%2020261022115654.png)

- 采用前端总线 FSB 的南北桥结构
- 采用 QPI 总线的南北桥结构
- 无北桥芯片的 CPU + PCIe 架构：CPU 直接连接内存与 PCIe 设备，传统北桥功能被集成进 CPU，芯片组主要承担低速 I/O
- 趋势：高速通道越来越靠近 CPU，低速 I/O 通过芯片组/桥接器汇聚

## 五、四种结构对比

| 结构 | 连接方式 | 优点 | 缺点 | 典型 |
|---|---|---|---|---|
| 单总线 | 所有部件共享一组总线 | 简单、便宜、易扩展 | 带宽瓶颈、冲突、可靠性低 | ISA、EISA、MCA |
| 双总线 | CPU-主存高速总线 + 系统/I/O 总线 | 高速与低速分离 | 需额外总线/桥接 | 早期 PC |
| 三总线 | 系统总线 + PCI + ISA，桥接 | 按速度进一步细分 | 结构复杂、桥多 | PCI/ISA 时代 |
| 高性能总线 | 分层多总线、桥接、点对点 | 高带宽、可扩展、高速设备靠近 CPU | 设计复杂 | AGP、PCIe、CPU+PCIe |

## 六、易错辨析

- 单总线不是“只有一根线”，而是“所有部件共享一组总线”
- 双总线不是任意两条总线，通常指“CPU-主存高速总线 + 系统/I/O 总线”或“系统总线 + I/O 总线”
- 三总线是层次结构（系统、PCI、ISA），不是数据/地址/控制三类功能总线
- 高性能总线是一种演化趋势/架构，不是某一条具体标准
- 桥接器的作用是隔离速度差异、缓冲、协议转换，不是简单“延长总线”
- PCIe 是点对点串行互连，不是共享并行总线；不要用传统“总线仲裁”套 PCIe
- “高速设备靠近 CPU”是布局趋势，不是硬性规定

## 七、考法透视

**常见题型**

- 给结构图，判断是单/双/三/高性能总线
- 判断某种结构解决了什么瓶颈
- 判断桥接器的作用
- 比较四种结构的优缺点
- 判断“三总线”与“数据/地址/控制三总线”的区别

**常见设错点**

1. 认为单总线只有一根线
2. 认为双总线就是数据总线 + 地址总线
3. 把“三总线”理解成数据/地址/控制三类
4. 认为高性能总线就是 PCI
5. 认为桥接器只是延长距离
6. 认为 PCIe 也需要集中式仲裁

## 九、费曼自测

1. 单总线结构的主要缺点是什么
   → 所有设备共享带宽，高速设备被低速设备拖累，冲突多、可靠性低、扩展受限

2. 双总线结构的核心思想是什么
   → 把 CPU-主存的高速访问与慢速 I/O 通信分离，减少速度差异对整体性能的影响

3. 三总线结构中的“三总线”指什么
   → 系统总线、PCI 总线、ISA 总线三层，按速度细分；不是数据/地址/控制三类

4. 桥接器的作用是什么
   → 连接不同层次/不同协议的总线，做速度隔离、缓冲与协议转换

5. 高性能总线结构的发展趋势有哪些
   → 分层多总线、桥接缓冲、高速设备靠近 CPU、桥接芯片高度集成、CPU+PCIe 架构
