## 三、核心公式总表

**主存容量**
- 容量 $=2^{\text{MAR 位数}}\times\text{MDR 位数}$
- MDR 位数 = 存储字长
- MAR 位数决定存储单元数

**时钟**
- $f=1/T$
- $1GHz$ 对应 $1ns$

**CPU 性能**
- $CPU时间=IC\times CPI\times T=\frac{IC\times CPI}{f}$
- $CPI=\frac{\text{总周期数}}{\text{指令数}}$
- $IPC=1/CPI$
- $MIPS=\frac{f}{CPI\times10^6}$
- $MFLOPS=\frac{\text{浮点运算次数}}{CPU时间\times10^6}$

**单位**
- $1B=8bit$
- 内存/Cache：$1KB=2^{10}B=1024B$
- 磁盘/网络：$1KB=10^3B=1000B$
- $1MB=8Mb$，$1GB=8Gb$
- $100Mbps=12.5MB/s$

## 四、易混术语

| 术语 | 含义 | 易混点 |
| --- | --- | --- |
| 机器字长 | CPU 一次处理位数 | ≠ 指令字长/存储字长 |
| 指令字长 | 一条指令位数 | 决定 PC 增量 |
| 存储字长 | 一个存储单元位数 | = MDR 位数 |
| 主存 | CPU 可直接访问 | 不等于辅存 |
| 辅存 | 外存，非易失 | 属于外设 |
| ISA | 指令系统，软硬件接口 | 不是微架构 |
| 微程序 | 微指令序列 | 属于硬件/固件 |
| CPI | 每条指令平均周期数 | 不是主频 |
| IPC | 每周期指令数 | = 1/CPI |
| MIPS | 每秒百万指令 | 不能跨 ISA 比较 |
| MFLOPS | 每秒百万浮点运算 | 只适合浮点程序 |
| 吞吐量 | 单位时间完成任务数 | ≠ 响应时间 |
| 响应时间 | 单个任务完成时间 | ≠ 吞吐量 |
