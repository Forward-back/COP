# 1.8 单位换算大全

**考纲定位**：计算机组成原理 · 第 1 章 计算机系统概述（1.8）｜重要度 ★★★★｜常见考法：选择题/大题（时间、频率、容量、传输率、bit 与 Byte）

**一句话核心**：时间/频率按十进制；内存/Cache 容量按 $2^{10}$；磁盘/网络传输率按 $10^3$；bit 与 Byte 永远差 8 倍

## 一、物理时间单位（从小到大）

| 单位 | 符号 | 换算关系 | 408 常见场景 |
| --- | --- | --- | --- |
| 皮秒 | ps | $1ps=10^{-12}s$ | 超高速时钟周期 |
| 纳秒 | ns | $1ns=10^{-9}s=10^3ps$ | CPU 主频周期（1GHz=1ns） |
| 微秒 | μs | $1\mu s=10^{-6}s=10^3ns$ | 指令执行、中断响应 |
| 毫秒 | ms | $1ms=10^{-3}s=10^3\mu s$ | 磁盘寻道、时间片 |
| 秒 | s | $1s=10^3ms$ | 程序运行时长、网络时延 |

**顺序**：ps < ns < μs < ms < s

## 二、频率单位（从小到大）

| 单位 | 符号 | 换算关系 | 408 常见场景 |
| --- | --- | --- | --- |
| 赫兹 | Hz | 1 次/秒 | 基本时钟 |
| 千赫兹 | kHz | $1kHz=10^3Hz$ | 低速总线 |
| 兆赫兹 | MHz | $1MHz=10^6Hz=10^3kHz$ | 早期 CPU 主频 |
| 吉赫兹 | GHz | $1GHz=10^9Hz=10^3MHz$ | 现代 CPU 主频 |
| 太赫兹 | THz | $1THz=10^{12}Hz=10^3GHz$ | 理论/极少 |

**顺序**：Hz < kHz < MHz < GHz < THz

**关系**：$f=1/T$，1GHz 对应 1ns

## 八、bit 与 Byte 的固定换算

**核心公式**

$$1B=8bit$$

**等价关系**

| 位单位 | 字节单位 | 换算 |
| --- | --- | --- |
| 8 bit | 1 B | $1B=8bit$ |
| 1 Kb | 1 KB | $1KB=8Kb$ |
| 1 Mb | 1 MB | $1MB=8Mb$ |
| 1 Gb | 1 GB | $1GB=8Gb$ |
| 1 Tb | 1 TB | $1TB=8Tb$ |

**速率换算**
- $1KB/s=8Kb/s$
- $1MB/s=8Mb/s$
- $1GB/s=8Gb/s$

**易错**
- 不是“1 bit = 1 Byte”；是 8 bit = 1 Byte
- 看到 Kb/KB、Mb/MB，先看大小写 b/B
- 网络带宽常标 b/s，下载速度常标 B/s，二者差 8 倍

## 九、408 口径与常见换算

**默认口径**
- 内存/Cache 容量：$1KB=2^{10}B=1024B$
- 磁盘/网络传输率：$1KB=10^3B=1000B$
- 题目明确“十进制/二进制”时，以题目为准

**常用换算**
- $1GHz=10^9Hz$，$T=1ns$
- $100Mbps=100/8MB/s=12.5MB/s$
- $1MB=8Mb$
- $1GB=8Gb$
- $2^{10}=1024$，$2^{20}\approx10^6$，$2^{30}\approx10^9$

**常见陷阱**
- Kb 与 KB 混用
- GHz 与 Gbps 混用
- 内存容量与磁盘标称混用 1024/1000
- bit 与 Byte 忘记乘/除 8
- “1KB=1000B”只在十进制场景成立
