## 一、物理时间单位（从小到大）

| 单位 | 符号 | 换算关系（从小到大） | 408常见场景 |
| :--- | :--- | :--- | :--- |
| 皮秒 | ps | 1 ps = 10⁻¹² s | 超高速时钟周期（GHz级以上） |
| 纳秒 | ns | 1 ns = 10⁻⁹ s = 10³ ps | CPU主频周期（1GHz = 1ns） |
| 微秒 | μs | 1 μs = 10⁻⁶ s = 10³ ns | 指令执行周期、中断响应时间 |
| 毫秒 | ms | 1 ms = 10⁻³ s = 10³ μs | 磁盘寻道时间、时间片 |
| 秒 | s | 1 s = 10³ ms | 操作系统运行时长、网络时延 |

> **从小到大顺序**：ps < ns < μs < ms < s

## 二、频率单位（从小到大）

| 单位 | 符号 | 换算关系（从小到大） | 408常见场景 |
| :--- | :--- | :--- | :--- |
| 赫兹 | Hz | 1 Hz = 1 次/秒 | 基本时钟频率 |
| 千赫兹 | KHz | 1 KHz = 10³ Hz | 低速总线时钟 |

> **从小到大顺序**：Hz < KHz < MHz < GHz < THz

## 三、存储容量（按位 bit，从小到大）

| 单位 | 符号 | 换算关系（从小到大） | 408常见场景 |
| :--- | :--- | :--- | :--- |
| 比特 | bit (b) | 最小单位 | 信息量基本单位 |

## 四、存储容量（按字节 Byte，从小到大）—— 二进制（×1024）

| 单位 | 符号 | 换算关系（从小到大） | 408常见场景 |
| :--- | :--- | :--- | :--- |
| 字节 | B (Byte) | 1 B = 8 bit | 最小编址单位 |
| 千字节 | KB | 1 KB = 2¹⁰ B = 1024 B | Cache行大小、内存块 |

## 八、bit 与 Byte 对应关系（固定换算）

| bit 单位 | 对应 Byte 单位 | 换算关系 |
| :--- | :--- | :--- |
| 1 b | 1 B | 8 b = 1 B |
| 1 Kb (1024 bit) | 1 KB (1024 B) | 1 KB = 8 Kb |
| 1 Mb (1024² bit) | 1 MB (1024² B) | 1 MB = 8 Mb |
| 1 Gb (1024³ bit) | 1 GB (1024³ B) | 1 GB = 8 Gb |
| 1 Tb (1024⁴ bit) | 1 TB (1024⁴ B) | 1 TB = 8 Tb |
| 1 Kb/s (1000 bit/s) | 1 KB/s (1000 B/s) | 1 KB/s = 8 Kb/s |
| 1 Mb/s (10⁶ bit/s) | 1 MB/s (10⁶ B/s) | 1 MB/s = 8 Mb/s |
| 1 Gb/s (10⁹ bit/s) | 1 GB/s (10⁹ B/s) | 1 GB/s = 8 Gb/s |

> **核心公式**：`1 B = 8 bit`，无论二进制还是十进制，bit 与 Byte 之间永远是 **×8 或 ÷8**。
