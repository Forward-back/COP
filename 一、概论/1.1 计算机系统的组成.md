# 1.1 计算机系统的组成

**考纲定位**：计算机组成原理 · 第 1 章 计算机系统概述（1.1）｜重要度 ★★★★｜常见考法：选择题（硬件/软件组成、五大部件、主机与外设）

**一句话核心**：计算机系统 = 硬件 + 软件；硬件是物理基础，软件是逻辑灵魂

![](../images/计算机系统组成.png)

## 一、硬件组成

**五大部件**
- 运算器：算术运算、逻辑运算
- 控制器：取指、译码、发控制信号
- 存储器：存放程序和数据
- 输入设备：把外部信息送入计算机
- 输出设备：把结果送出计算机

**现代组织**
- 运算器 + 控制器集成在 CPU 中
- CPU + 主存称为“主机”
- 输入/输出设备、辅存称为“外设”

**易错**
- CPU 不只是运算器 + 控制器，还包含寄存器、Cache 等
- 主存属于主机；辅存属于外设
- 运算器不只做算术，还做逻辑运算

## 二、软件组成

| 类别 | 作用 | 例子 |
| --- | --- | --- |
| 系统软件 | 管理硬件、支持程序运行 | 操作系统、编译程序、汇编程序、数据库管理系统、驱动程序 |
| 应用软件 | 解决用户具体问题 | 浏览器、办公软件、游戏、科学计算程序 |

**提炼**
- 系统软件是硬件与用户之间的桥梁
- 应用软件依赖系统软件提供的运行环境
- 固件（BIOS/UEFI）介于硬件与软件之间，通常归入软件范畴

**易错**
- 操作系统是系统软件，不是应用软件
- 编译程序是系统软件，不是应用软件
- 固件不是“硬件”；它存放在 ROM 中，但属于程序

## 三、软硬件关系

- 硬件是基础，软件是灵魂
- 软件通过指令系统驱动硬件
- 同一功能可以用硬件实现，也可以用软件模拟，二者逻辑等价
