# 4.28 Cache——替换算法（习题课二）

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.28）｜重要度 ★★★★｜常见考法：大题（组相联替换、LRU 位、Cache 容量、地址划分）

**一句话核心**：组相联替换只在目标组内进行；先算组号，再在组内按 LRU 位/访问顺序选 victim

**考什么**：组相联的组号计算与组内替换
**常见错因**
- 把组号当行号
- 在全局范围选替换行，而不是在组内
- LRU 位更新错误

**解题模板**
1. 组数 = 总行数 / 路数
2. 组号 = 主存块号 mod 组数
3. 用组号定位组
4. 组内按 LRU/FIFO 选 victim
5. 更新 Tag、有效位、LRU 位

## 例题二

![](../../images/Pasted%20image%2020260923165753.png)

**解答**

### 第一问

![](../../images/Pasted%20image%2020260923165832.png)

**考什么**：Cache 容量/行数/组数计算
**常见错因**
- 把数据容量当总容量
- 忘记除以块大小
- 组数算成行数

**解题模板**
1. 行数 = 数据容量 / 块大小
2. 组数 = 行数 / 路数
3. 总容量 = 行数 × (数据 + Tag + 有效位 + 脏位)

### 第二问

![](../../images/Pasted%20image%2020260923165918.png)

![](../../images/Pasted%20image%2020260923165944.png)

**考什么**：地址划分与组号/Tag
**常见错因**
- Offset 位数算错
- 组号位数用行数而不是组数
- Tag 忘记减去组号和 Offset

**解题模板**
1. Offset = $\log_2$(块大小)
2. 组号 = $\log_2$(组数)
3. Tag = 地址位数 − 组号 − Offset
4. 按“Tag | 组号 | Offset”切分

### 第三问

![](../../images/Pasted%20image%2020260923170035.png)

![](../../images/Pasted%20image%2020260923170109.png)

**考什么**：替换过程与命中率
**常见错因**
- 命中后未更新 LRU
- 缺失时未考虑组内空行
- 把替换次数当缺失次数

**解题模板**
1. 逐项访问，记录组号
2. 组内有空行 → 直接放入
3. 组满 → 按 LRU 选 victim
4. 命中 → 更新 LRU
5. 统计命中/缺失/替换次数
