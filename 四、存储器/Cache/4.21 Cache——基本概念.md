# 4.21 Cache——基本概念

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.21）｜重要度 ★★★★★｜常见考法：选择题/大题（局部性、命中率、平均访问时间、Cache 容量、块大小）

**一句话核心**：Cache 是 CPU 与主存之间的 SRAM 缓冲，靠程序局部性把常用数据复制到高速小容量存储器

## 一、作用

![](../../images/Pasted%20image%2020260919192318.png)

**提炼**
- 主存用 DRAM，容量大、成本低，但速度跟不上 CPU
- Cache 用 SRAM，容量小、成本高，但速度快
- Cache 存放主存中“经常访问或即将访问”的数据副本
- CPU 先访问 Cache，命中则直接取数，未命中再访问主存

**易错**
- Cache 不是“主存的替代品”，而是主存的副本
- Cache 对程序员透明，由硬件自动管理
- Cache 的内容是主存内容的子集，不是全部

## 二、程序局部性

![](../../images/Pasted%20image%2020260919192423.png)

**两类局部性**
- 时间局部性：刚被访问的数据/指令，近期可能再次被访问
- 空间局部性：刚被访问的地址附近，近期可能被访问

**例题**

![](../../images/Pasted%20image%2020260919192458.png)

**提炼**
- 循环、数组、顺序指令流是局部性的典型来源
- Cache 按“块”调入，一次取一块，利用空间局部性
- 时间局部性靠保留最近访问的块

**易错**
- 局部性是程序行为，不是 Cache 的属性
- 时间局部性不等于“数据永远不变”
- 空间局部性要求块内数据连续；跳跃访问会降低命中率

## 三、访问时间

### 3.1 命中缓存时

![](../../images/Pasted%20image%2020260919192648.png)

**提炼**
- 命中时只需访问 Cache，时间记为 $t_c$
- 命中率 $h$ 越高，平均访问时间越接近 $t_c$

### 3.2 未命中缓存时（数据缺失）

![](../../images/Pasted%20image%2020260919192805.png)

**提炼**
- 未命中时要从主存调入数据，时间记为 $t_m$
- 若采用“先访问 Cache 再访问主存”，平均访问时间公式为
  $$t_a = h t_c + (1-h)t_m$$
- 若采用“同时访问 Cache 和主存”，未命中时只需补上主存时间，公式会不同；408 默认前者

**易错**
- $t_m$ 是未命中时的总时间，可能包含主存访问 + 调入 Cache
- 命中率与缺失率之和为 1
- 公式中的 $h$ 是命中率，不是缺失率

## 四、数据分块

![](../../images/Pasted%20image%2020260919192938.png)

![](../../images/Pasted%20image%2020260919193008.png)

**提炼**
- Cache 与主存按“块”交换数据，块大小相同
- 块大小 = 一次调入 Cache 的数据量
- 块太小：空间局部性利用不足，命中率低
- 块太大：调入开销大，冲突概率增加，可能降低命中率
- 块大小通常为 4~64 字节

**易错**
- Cache 行（line）与主存块（block）通常一一对应
- 块大小不是越大越好；要折中
- 块内地址偏移位数 $=\log_2(\text{块大小})$

## 五、评价指标

![](../../images/Pasted%20image%2020260919193203.png)

**公式**

$$h=\frac{n_c}{n_c+n_m}$$

$$t_a=h t_c+(1-h)t_m$$

$$e=\frac{t_c}{t_a}=\frac{1}{h+(1-h)\frac{t_m}{t_c}}$$

- $n_c$：命中次数；$n_m$：未命中次数
- $t_c$：命中时间；$t_m$：未命中时间
- $e$：访问效率，越接近 1 越好

**例**：$h=0.95$，$t_c=1ns$，$t_m=100ns$

$$t_a=0.95\times1+0.05\times100=5.95ns$$

$$e=1/5.95\approx16.8\%$$

**易错**
- 平均访问时间不是 $h t_c + (1-h)t_c$
- 命中率很高但 $t_m$ 很大时，平均时间仍可能被拖慢
- Cache 容量、块大小、映射方式、替换算法都会影响命中率
