# 4.30 Cache——Cache的分类和应用

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.30）｜重要度 ★★★★｜常见考法：选择题（统一/分离 Cache、多级 Cache、L1/L2/L3、软件 Cache 了解）

**一句话核心**：硬件 Cache 分统一/分离/多级；分离解决指令与数据争用，多级解决容量与速度矛盾；软件 Cache 只需了解

## 一、硬件Cache

### 1.1 统一Cache

![](../../images/Pasted%20image%2020260923170514.png)

**提炼**
- 指令和数据共用同一个 Cache
- 结构简单、利用率高
- 但取指和取数可能争用同一 Cache，产生结构冲突

### 1.2 分离Cache

![](../../images/Pasted%20image%2020260923170545.png)

**提炼**
- 指令 Cache（I-Cache）和数据 Cache（D-Cache）分开
- 避免取指与取数争用，支持流水线并行
- 成本较高，容量利用率可能下降
- 现代 CPU 的 L1 通常分离，L2/L3 通常统一

### 1.3 多级Cache

![](../../images/Pasted%20image%2020260923170631.png)

**提炼**
- L1 最快、最小，紧挨 CPU
- L2 较大、较慢，通常片上
- L3 更大、更慢，多核共享
- 多级 Cache 逐级包含或逐级不包含，408 主要考“越靠近 CPU 越快越小”

**易错**
- 统一/分离是“指令与数据是否共用”的分类
- 多级 Cache 是“层次”的分类，不是“统一/分离”的对立
- L1 分离、L2 统一是常见设计，但不是绝对
- Cache 级别越高，速度越慢、容量越大

## 二、软件Cache

### 2.1 Buffer Cache

![](../../images/Pasted%20image%2020260923170715.png)

- 操作系统用主存缓存磁盘数据，减少磁盘 I/O
- 属于软件管理的缓存，不是 CPU Cache
- 408 计组只需了解概念

### 2.2 web Cache

![](../../images/Pasted%20image%2020260923170742.png)

**注**：具体细节见计网万维网部分

- 代理服务器/浏览器缓存网页资源
- 属于应用层缓存，与 CPU Cache 无关
- 408 计组不展开

**易错**
- 软件 Cache 不是“用软件模拟的 CPU Cache”
- Buffer Cache 属于 OS，web Cache 属于网络应用
- 计组考试重点是硬件 Cache，软件 Cache 只做背景了解
