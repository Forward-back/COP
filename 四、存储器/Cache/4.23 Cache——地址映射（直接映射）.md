# 4.23 Cache——地址映射（直接映射）

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.23）｜重要度 ★★★★★｜常见考法：大题（地址划分、Tag/Index/Offset、Cache 容量、命中判断）

**一句话核心**：直接映射中每个主存块只能放到唯一一个 Cache 行；地址拆成“Tag + 行号 + 块内偏移”

## 一、地址映射

### 1.1 Cache与主存结构

![](../../images/Pasted%20image%2020260919200319.png)

**提炼**
- 主存按块划分，Cache 按行划分，块与行大小相同
- 直接映射：主存块号 mod Cache 行数 = Cache 行号
- 一个主存块只能映射到一个固定行；多个主存块争用同一行

### 1.2 Cache每一行（槽）的具体内容

![](../../images/Pasted%20image%2020260919200426.png)

**Cache 行内容**
- 有效位（Valid）：该行数据是否有效
- 标记（Tag）：区分当前行装的是哪个主存块
- 数据块（Data）：从主存调入的整块数据
- 脏位（Dirty）：写回策略下使用，表示是否与主存不一致

**易错**
- Tag 不是主存块号的全部，而是“块号中除去行号后的高位”
- 有效位为 0 时，Tag 无意义，不能算命中
- Cache 总容量 = 数据容量 + Tag + 有效位 + 脏位等额外开销

## 二、直接映射的方法

### 2.1 结构

![](../../images/Pasted%20image%2020260919200643.png)

**映射规则**

$$\text{Cache 行号} = \text{主存块号} \bmod \text{Cache 行数}$$

**地址划分**

$$\text{主存地址} = \text{Tag} \mid \text{Index} \mid \text{Offset}$$

- Offset 位数 $=\log_2(\text{块大小})$
- Index 位数 $=\log_2(\text{Cache 行数})$
- Tag 位数 $=$ 地址总位数 $-$ Index 位数 $-$ Offset 位数

**例**：32 位地址，Cache 64KB，块大小 16B
- 行数 $=64KB/16B=4096=2^{12}$
- Offset $=4$ 位
- Index $=12$ 位
- Tag $=32-12-4=16$ 位

### 2.2 读取方式

![](../../images/Pasted%20image%2020260919201031.png)

**步骤**
1. 用 Index 找到唯一 Cache 行
2. 比较该行 Tag 与地址 Tag
3. 有效位为 1 且 Tag 相同 → 命中
4. 否则缺失，从主存调入该块，替换这一行
5. 按 Offset 从块中取出目标字

**易错**
- 直接映射不需要比较所有行，只比较一行
- 命中判断要同时看有效位和 Tag
- Offset 不参与 Tag 比较，只用于块内选字

### 2.3 硬件逻辑实现

![](../../images/Pasted%20image%2020260919201252.png)

**提炼**
- 地址寄存器 → Index 译码 → 选中一行
- Tag 比较器：地址 Tag 与该行 Tag 比较
- 命中信号 = 有效位 & Tag 相等
- 未命中时，用主存地址取块，写入选中行，更新 Tag 和有效位

## 三、总结

![](../../images/Pasted%20image%2020260919201351.png)

| 维度 | 直接映射 |
| --- | --- |
| 映射规则 | 行号 = 块号 mod 行数 |
| 地址划分 | Tag / Index / Offset |
| 比较器 | 1 个 |
| 命中判断 | 有效位 & Tag 相等 |
| 冲突 | 多个块争用同一行，冲突缺失多 |
| 成本 | 最低 |
| 替换 | 无需选择，只能替换固定行 |

**公式汇总**

$$\text{Offset}=\log_2(\text{块大小})$$

$$\text{Index}=\log_2(\text{Cache 行数})$$

$$\text{Tag}=\text{地址位数}-\text{Index}-\text{Offset}$$

$$\text{Cache 总容量}=\text{行数}\times(\text{数据位}+\text{Tag 位}+\text{有效位}+\text{脏位})$$

**易错**
- 直接映射的“直接”指映射位置唯一，不是“直接访问主存”
- Cache 行数不等于 Cache 容量；行数 = 容量 / 块大小
- Cache 总容量要加 Tag/有效位/脏位，题目问“数据容量”时不要加
- 块大小越大，Offset 位数越多，Tag 位数越少，但冲突和调入开销也变化
