# 4.37 虚拟存储器——习题课

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.37）｜重要度 ★★★★★｜常见考法：大题（虚地址/物理地址、页表、TLB、Cache、访问次数）

**一句话核心**：先拆虚拟地址，再查 TLB/页表得物理地址，最后拆物理地址查 Cache；每一步都只切分、不重叠

## 例题一

![](../../images/Pasted%20image%2020260923202259.png)

### 第一问

![](../../images/Pasted%20image%2020260923202320.png)

**考什么**：虚拟地址/物理地址位数、页大小、VPN/PPN
**常见错因**
- 忘记页内偏移位数
- 虚拟地址位数用物理内存容量算
- VPN/PPN 位数混用

**解题模板**
1. 页大小 → Offset = $\log_2$(页大小)
2. 虚拟地址位数 − Offset = VPN 位数
3. 物理地址位数 − Offset = PPN 位数
4. 虚拟地址空间 = $2^{\text{虚拟地址位数}}$；物理内存 = $2^{\text{物理地址位数}}$

### 第二问

![](../../images/Pasted%20image%2020260923202434.png)

**考什么**：页表项数、页表大小、页表级数
**常见错因**
- 页表大小 = 页数 × 页大小（错误）
- 忘记每项字节数
- 多级页表索引位数分配错误

**解题模板**
1. 页表项数 = $2^{\text{VPN}}$
2. 页表大小 = 项数 × 每项字节数
3. 若页表大小 > 一页，需要多级页表
4. 多级页表：每级索引位数 × 级数 + Offset = 虚拟地址位数

### 第三问

![](../../images/Pasted%20image%2020260923202523.png)

**考什么**：TLB 的地址划分（Tag/Index/Offset）
**常见错因**
- TLB 索引来自物理地址（错，来自虚拟页号）
- TLB 没有 Offset
- TLB 组数/路数混淆

**解题模板**
1. VPN 拆成 TLB Tag + TLB Index
2. TLB Index = $\log_2$(TLB 组数)
3. TLB Tag = VPN − TLB Index
4. Offset 不变

### 第四问

![](../../images/Pasted%20image%2020260923202549.png)

**考什么**：物理地址查 Cache 的 Tag/Index/Offset
**常见错因**
- 用虚拟地址查 Cache（未翻译）
- Cache 索引位数用行数/组数混淆
- 忘记 Cache 块大小

**解题模板**
1. 先由 TLB/页表得物理地址
2. Cache Offset = $\log_2$(块大小)
3. Cache Index = $\log_2$(Cache 行数/组数)
4. Cache Tag = 物理地址 − Index − Offset

## 例题二

![](../../images/Pasted%20image%2020260923202638.png)

**考什么**：TLB + 页表 + Cache 的综合访问次数
**常见错因**
- TLB 命中后仍算一次页表访问
- 页命中与 Cache 命中混淆
- 缺页处理时间漏算

**解题模板**
1. 查 TLB：命中 → 无页表访问；缺失 → 查页表
2. 页表项可能在 Cache 中；命中则少一次主存访问
3. 得物理地址后查 Cache
4. 统计主存访问次数：页表缺失 + 数据缺失
5. 缺页另加辅存访问
