# 4.33 虚拟存储器——地址映射和页表

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.33）｜重要度 ★★★★★｜常见考法：大题（VPN/PPN/Offset、页表项、页表大小、地址转换、PTBR）

**一句话核心**：虚拟地址拆成 VPN + Offset，页表把 VPN 翻译成 PPN，Offset 原样保留；页表基址由 PTBR 给出

**页表项（PTE）常见字段**

| 字段 | 作用 |
| --- | --- |
| 有效位/存在位 | 该页是否在主存 |
| 物理页号 PPN | 映射到的物理页 |
| 脏位 | 该页是否被修改 |
| 访问位/引用位 | 最近是否被访问，供替换算法 |
| 保护位 | 读/写/执行权限 |
| 禁止缓存位 | 是否允许 Cache |

**提炼**
- 页表是“VPN → PTE”的数组，下标是 VPN
- 页表项不只存 PPN，还存控制位
- 页表本身在主存中，PTBR 保存页表基址
- 每个进程有自己的页表，进程切换时切换 PTBR

**易错**
- 页表项不是“物理地址”，而是“物理页号 + 控制位”
- 有效位为 0 表示页不在主存，不代表页不存在于虚拟地址空间
- 页表大小 = 页表项数 × 每项字节数，不是页数 × 页大小

## 二、虚拟地址与物理地址

![](../../images/Pasted%20image%2020260923184616.png)

**地址划分**

$$\text{虚拟地址}=\text{VPN}\mid\text{Offset}$$

$$\text{物理地址}=\text{PPN}\mid\text{Offset}$$

- Offset 位数 = $\log_2$(页大小)
- VPN 位数 = 虚拟地址位数 − Offset 位数
- PPN 位数 = 物理地址位数 − Offset 位数

**页表大小**

$$\text{页表项数}=2^{\text{VPN 位数}}$$

$$\text{页表大小}=\text{页表项数}\times\text{每项字节数}$$

**例**：32 位虚拟地址，4KB 页，页表项 4B
- Offset = 12 位
- VPN = 20 位
- 页表项数 = $2^{20}$
- 页表大小 = $2^{20} \times 4B = 4MB$

**易错**
- 页表大小可能很大，因此实际系统用多级页表
- VPN 位数由虚拟地址和页大小决定，不由物理内存决定
- Offset 在地址转换中不变

## 三、虚拟地址和物理地址的转化

![](../../images/Pasted%20image%2020260923184750.png)

**转换步骤**
1. 从虚拟地址中取出 VPN 和 Offset
2. 用 PTBR 找到页表基址
3. 用 VPN 作下标查页表，得到 PTE
4. 检查有效位/权限
5. 取出 PPN
6. 物理地址 = PPN 拼接 Offset
7. 用物理地址访问 Cache/主存

**缺页处理**
- 有效位为 0 → 缺页异常
- OS 从辅存调入该页到主存
- 更新页表项（PPN、有效位）
- 重新执行触发缺页的指令

**易错**
- 页表查询本身需要访问主存；TLB 就是为加速这一步
- 页表项的有效位检查在地址转换中完成
- 缺页后不是“继续执行下一条”，而是重新执行当前指令

## 四、例题

### 4.1 例题一

![](../../images/Pasted%20image%2020260923184827.png)

**第四问**

![](../../images/Pasted%20image%2020260923184856.png)

![](../../images/Pasted%20image%2020260923184913.png)

**考什么**：虚拟地址/物理地址位数、页表项、地址转换
**常见错因**
- 忘记 Offset 位数
- 用虚拟地址位数算物理页号
- 页表大小算成页数 × 页大小

**解题模板**
1. 页大小 → Offset
2. 虚拟地址 − Offset → VPN
3. 物理地址 − Offset → PPN
4. 页表项数 = $2^{\text{VPN}}$
5. 页表大小 = 项数 × 每项字节数
6. 物理地址 = PPN 拼 Offset

### 4.2 例题二

![](../../images/Pasted%20image%2020260923184959.png)

**考什么**：页表项内容与地址映射
**常见错因**
- 把页表项当物理地址
- 忽略有效位/权限位
- 忘记页表基址 PTBR

**解题模板**
1. 由 VPN 定位页表项
2. 读 PTE：有效位、PPN、权限
3. 有效则拼物理地址；无效则缺页
4. 检查权限是否允许访问
