# 4.3 存储器的性能指标和存储系统层次结构

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.3）｜重要度 ★★★★★｜常见考法：选择题/大题（容量、存取时间、存取周期、带宽、层次结构）

**一句话核心**：容量看“字长 × 单元数”，速度看“存取时间/存取周期”，吞吐看“数据宽度 ÷ 存取周期”

## 一、性能指标

### 1.1 存储容量

![](../../images/Pasted%20image%2020260911164716.png)

**公式**

$$\text{存储容量} = \text{存储字长} \times \text{存储单元数}$$

- 存储字长：一个存储单元存放的二进制位数
- 存储单元数：由 MAR 的位数决定，$2^n$ 个单元
- 容量单位：$1B=8bit$，$1KB=2^{10}B$，$1MB=2^{20}B$，$1GB=2^{30}B$

**易错**
- 容量单位是字节（B）还是位（b），题目经常在这里设陷阱
- 存储字长 ≠ 机器字长；存储字长是一个存储单元的位数
- MAR 位数决定“有多少个单元”，MDR 位数等于存储字长

### 1.2 存取速度

![](../../images/Pasted%20image%2020260911164804.png)

| 指标 | 定义 | 关键点 |
| --- | --- | --- |
| 存取时间 $T_a$ | 一次读/写操作所需时间 | 从启动到完成 |
| 存取周期 $T_m$ | 连续两次访问所需的最小间隔 | $T_m \ge T_a$，含恢复时间 |
| 存储器带宽 $B_m$ | 单位时间传输的信息量 | $B_m = \text{数据宽度} / T_m$ |

**公式**

$$B_m = \frac{\text{数据宽度}}{T_m}$$

**例**：存取周期 $T_m=50ns$，数据宽度 32 位，则

$$B_m = \frac{32bit}{50ns} = 640Mbit/s = 80MB/s$$

**易错**
- 存取时间与存取周期不是一回事；DRAM 读后需要恢复时间，$T_m > T_a$
- 带宽的单位是 bit/s 或 B/s，注意 bit 与 Byte 的换算
- 数据宽度不是地址线位数；数据线位数决定一次能传多少位

## 二、存储系统层次结构

![](../../images/Pasted%20image%2020260911165002.png)

**提炼**
- 层次结构：CPU 寄存器 → Cache → 主存 → 辅存
- 越往上：速度越快、容量越小、单位成本越高
- 越往下：速度越慢、容量越大、单位成本越低
- 上层作为下层的缓存，靠程序局部性提高整体性能

**两个经典层次**
- Cache—主存层次：解决 CPU 与主存速度差距，由硬件自动管理
- 主存—辅存层次：解决主存容量不足，由 OS 与硬件共同管理，即虚拟存储器

**易错**
- Cache—主存层次对程序员透明；主存—辅存层次对程序员可见（地址空间变大）
- 层次结构不是“把数据全部复制到上层”，而是按块调入、按需替换
- 存储器的“带宽”与总线的“带宽”计算方式类似，但对象不同
