# 4.1 存储器概述

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.1）｜重要度 ★★★★｜常见考法：选择题（存储系统层次、主存/辅存分工、容量与速度取舍）

**一句话核心**：现代计算机以存储器为中心；用“寄存器—Cache—主存—辅存”的层次结构，在容量、速度、成本之间折中

## 一、存储器的地位

![](../../images/Pasted%20image%2020260911162753.png)

**提炼**
- 存储器存放指令和数据，是计算机能够“存储程序”的物理基础
- 现代计算机以存储器为中心：CPU、I/O 设备都通过总线与主存交换信息
- 存储系统的目标是“容量大、速度快、成本低”，三者互相制约，靠层次结构折中

**易错**
- “以存储器为中心”不等于 CPU 不重要；它描述的是数据流动的组织方式
- 容量、速度、成本不可能同时最优；层次结构就是用上层的高价换速度、用下层的大容量补容量

## 二、主存与辅存

![](../../images/Pasted%20image%2020260911162828.png)

| 维度 | 主存 | 辅存 |
| --- | --- | --- |
| 作用 | 存放当前运行的程序和数据 | 存放暂时不用的程序和数据 |
| 速度 | 快 | 慢 |
| 容量 | 较小 | 更大 |
| 成本 | 高 | 低 |
| 断电 | 通常易失（RAM） | 通常非易失 |
| CPU 访问 | 可直接访问 | 不能直接访问，需先调入主存 |

**提炼**
- 主存是 CPU 能直接访问的存储器；辅存是主存的“后备仓库”
- 程序要运行，必须先由辅存调入主存；虚拟存储器就是把这一过程自动化
- 主存与辅存的层次，是“容量—速度”折中的最典型体现

**易错**
- 主存不等于内存条上的全部芯片；ROM、Cache 也可能在主存层次中讨论
- 辅存容量大但速度慢，不能因为“容量大”就认为它比主存重要
- 主存/辅存的划分依据是“CPU 能否直接访问”，不是“是否在主机箱内”

## 三、存储系统层次结构

```
CPU 寄存器
   ↓ 更快、更小、更贵
Cache
   ↓
主存
   ↓
辅存（磁盘、SSD、磁带、光盘）
   ↓ 更慢、更大、更便宜
```

**提炼**
- 越靠近 CPU，速度越快、容量越小、单位成本越高
- 越远离 CPU，速度越慢、容量越大、单位成本越低
- 上层是下层的缓存：Cache 缓存主存数据，主存缓存辅存数据
- 层次结构有效的根本原因：程序访问的局部性

**易错**
- 层次结构不是“把同样数据复制一份就完了”，每一层都要有地址映射、替换和一致性机制
- Cache 对程序员透明；虚拟存储器由 OS 与硬件共同管理，二者不是同一层
- 寄存器不属于“存储器层次”的常规考点，但它是最高层，速度最快、容量最小
