## 二、一条主线

```
存储层次与指标（4.1-4.3）
   ↓ 容量、速度、成本
主存芯片与扩展（4.4-4.20）
   ↓ SRAM/DRAM/ROM → 位/字扩展 → 多体交叉
Cache（4.21-4.30）
   ↓ 映射 → 替换 → 写策略
虚拟存储器（4.31-4.37）
   ↓ 页表 → TLB → Cache 组合
```

- 主存解决“数据放在哪、怎么读写”
- 扩展解决“芯片不够大、怎么拼”
- Cache 解决“CPU 太快、主存太慢”
- 虚存解决“程序太大、主存不够”

## 三、核心公式总表

**性能指标**
- 存储容量 $=$ 存储字长 $\times$ 存储单元数
- 带宽 $B_m=$ 数据宽度 $/T_m$
- 平均访问时间 $t_a=h t_c+(1-h)t_m$
- 访问效率 $e=t_c/t_a$

**主存扩展**
- 位扩展：芯片数 $=$ 目标字长 $/$ 单片字长
- 字扩展：组数 $=$ 目标字数 $/$ 单片字数
- 字位同时：芯片总数 $=$ 组数 $\times$ 每组片数
- 地址位数 $=\log_2$(字数)；数据位数 $=$ 字长

**多体交叉**
- 低位交叉：模块号 $=$ 地址 mod 模块数
- 流水条件：$T=m\tau$
- 连续 $n$ 次访问总时间：$T_{\text{总}}=(m+n-1)\tau$

**Cache**
- 行数 $=$ Cache 数据容量 $/$ 块大小
- Offset $=\log_2$(块大小)
- 直接：Index $=\log_2$(行数)
- 组相联：组号 $=\log_2$(组数)，组数 $=$ 行数 $/$ 路数
- Tag $=$ 地址位数 $-$ Index/组号 $-$ Offset
- Cache 总容量 $=$ 行数 $\times$(数据位 $+$ Tag $+$ 有效位 $+$ 脏位)
- LRU 位 $=\log_2$(路数)

**虚拟存储器**
- 虚拟地址 $=$ VPN $\mid$ Offset
- 物理地址 $=$ PPN $\mid$ Offset
- 页大小 $=2^{\text{Offset}}$
- 页表项数 $=2^{\text{VPN}}$
- 页表大小 $=$ 页表项数 $\times$ 每项字节数
- TLB 命中 → 页一定命中
- 理想情况：页表项在 Cache、数据在 Cache → 2 次 Cache 访问，0 次主存访问

## 四、易混术语

| 术语 | 含义 | 易混点 |
| --- | --- | --- |
| SRAM | 双稳态触发器，无需刷新 | 仍易失 |
| DRAM | 1T1C，需刷新 | 读是破坏性的 |
| ROM | 正常以读为主 | Flash 可写但仍属 ROM 家族 |
| MAR | 地址寄存器 | 位数决定单元数 |
| MDR | 数据寄存器 | 位数 = 存储字长 |
| 位扩展 | 增加字长 | 字数不变 |
| 字扩展 | 增加字数 | 字长不变 |
| 单体多字 | 同一地址并行读多个字 | 提升带宽 |
| 多体交叉 | 低位模块流水线 | 提升带宽 |
| 高位交叉 | 高位模块 | 主要扩容量 |
| 直接映射 | 行号 = 块号 mod 行数 | 1 个比较器 |
| 全相联 | 任意块任意行 | 无 Index |
| 组相联 | 组间直接、组内全相联 | 组号不是行号 |
| 写回 | 只改 Cache，脏位延迟写回 | 需脏位 |
| 写穿 | 同时写 Cache 和主存 | 写带宽压力大 |
| 写分配 | 写缺失先调入 | 常配写回 |
| 非写分配 | 写缺失直接写主存 | 常配写穿 |
| TLB | 页表项的 Cache | 不是数据 Cache |
| 页表 | VPN → PPN 的映射 | 在主存 |
| 缺页 | 页不在主存 | OS 处理，不是 Cache 缺失 |
