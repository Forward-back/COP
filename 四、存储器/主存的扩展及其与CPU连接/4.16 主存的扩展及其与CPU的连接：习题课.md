# 4.16 主存的扩展及其与CPU的连接：习题课

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.16）｜重要度 ★★★★★｜常见考法：大题（芯片数、地址范围、MAR 位数、ROM/RAM 混合扩展）

**一句话核心**：先算“需要多少组、每组多少片”，再算“地址线怎么分、片选怎么接”；ROM 与 RAM 只是地址范围不同

## 一、知识回顾

### 1.1 主存的扩展

![](../../images/Pasted%20image%2020260916152612.png)

**提炼**
- 位扩展：字数不变，字长增加，芯片共用地址、分占数据线
- 字扩展：字长不变，字数增加，芯片共享数据、用片选分组
- 字位同时扩展：先位扩展凑字长，再字扩展凑字数

### 1.2 主存与CPU的连接

![](../../images/Pasted%20image%2020260916152822.png)

**ROM 的生态位**
- 存放启动程序（BIOS/引导程序）：CPU 复位后从固定地址取指
- 存放固化程序/常量：底层驱动、配置表、字模库
- 统一编址：ROM 与 RAM 共享地址空间，用普通访存指令读 ROM
- 只读保护：对 ROM 的写操作通常被忽略或报错

**易错**
- ROM 也是主存的一部分，不是“外设”
- 统一编址下不需要专用 I/O 指令
- ROM 的地址范围由译码器分配，不是固定从 0 开始

## 二、真题

### 2.1 2009 年题 15

![](../../images/Pasted%20image%2020260916153429.png)

**考什么**：ROM/RAM 混合扩展的芯片数
**常见错因**：把 ROM 和 RAM 的芯片数混在一起；忘记位扩展
**解题模板**
1. ROM：$4KB / 2KB = 2$ 片（$2K \times 8$ 已够 8 位）
2. RAM：$60KB / 4KB = 15$ 组；每组用 2 片 $4K \times 4$ 位扩展成 8 位
3. RAM 芯片数 $=15 \times 2=30$
4. 答案 D（2，30）

### 2.2 2010 年题 15

![](../../images/Pasted%20image%2020260916153504.png)

**考什么**：芯片地址范围与组基址
**常见错因**：把片内地址与片选地址混；直接用地址除以单片容量
**解题模板**
1. $2K \times 4$ 芯片两片一组，组成 $2K \times 8$
2. 每组地址范围 $2K=0800H$
3. 地址 $0B1FH$ 落在第二组（$0800H\sim 0FFFH$）
4. 该组基址 $0800H$，答案 D

### 2.3 2011 年题 15

![](../../images/Pasted%20image%2020260916153543.png)

**考什么**：MAR 位数与地址空间的关系
**常见错因**：用实际安装容量算 MAR 位数；忘记按字节编址
**解题模板**
1. 主存地址空间 $64MB=2^{26}B$
2. 按字节编址，地址位数 $=26$
3. MAR 位数至少 26，答案 D
4. 实际装 32MB 不影响 MAR 位数；MAR 由地址空间决定

### 2.4 2021 年题 15

![](../../images/Pasted%20image%2020260916153648.png)

**考什么**：字位同时扩展的芯片总数；按字编址时地址单元数 × 字长才是总容量
**常见错因**：把“按字编址”误当“按字节编址”；只算容量比，忘记数据总线 32 位需要位扩展
**解题模板**
1. 地址范围 $000000H\sim 3FFFFFH$，共 $4M$ 个地址单元
2. 按字编址、字长 32 位，总容量 $=4M \times 32bit=4M \times 4B=16MB$
3. 每片 $512K \times 8$ 位 $=512KB$
4. 芯片数 $=16MB/512KB=32$
5. 也可分组算：$4M/512K=8$ 组，每组 4 片位扩展，共 32 片
6. 答案 C（32）
