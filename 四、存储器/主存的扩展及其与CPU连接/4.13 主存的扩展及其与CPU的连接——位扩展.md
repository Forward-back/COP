# 4.13 主存的扩展及其与CPU的连接——位扩展

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.13）｜重要度 ★★★★★｜常见考法：大题（芯片数、地址线/数据线、片选、读写流程、地址范围）

**一句话核心**：位扩展增加字长，不增加字数；多片芯片共用地址线、分占数据线，同时被选中

## 一、位扩展的适用场景及举例

**场景实例**

![](../../images/Pasted%20image%2020260916143517.png)

**提炼**
- 当单片芯片的位数不足、字数够用时，用多片并联增加字长
- 例：用 32 片 $256K \times 1$ 的芯片组成 $256K \times 32$ 的存储器
- 32 片芯片共用 18 位地址线，每片输出 1 位，拼成 32 位数据
- 总容量 $=256K \times 32$ 位

**四步模板**
1. 确定目标字数与字长
2. 芯片数 $=$ 目标字长 / 单片字长（字数不变）
3. 地址线位数由字数决定，所有芯片共用
4. 数据线按芯片分位连接，片选同时有效

### 1.1 与CPU连接：初始状态

![](../../images/Pasted%20image%2020260916143639.png)

**提炼**
- CPU 的地址线 $A_{17}\sim A_0$ 接到所有芯片
- 数据线 $D_{31}\sim D_0$ 按芯片分配：每片接 1 位
- MREQ、R/W 等控制信号接到所有芯片
- 片选信号统一有效，选中全部 32 片

### 1.2 与CPU连接：读操作

![](../../images/Pasted%20image%2020260916143759.png)

**流程**
1. CPU 发出地址，送入所有芯片的地址端
2. MREQ 有效，CS 有效，32 片芯片同时被选中
3. R/W = 1，表示读操作；WE 无效
4. 每片芯片输出 1 位，32 片并行输出 32 位
5. 数据经数据总线送入 CPU

**易错**
- 32 片芯片是“32 片存储芯片并行输出”，不是“32 个存储元”
- 地址线共用，数据线分开；不要把所有数据线并在一起
- 片选必须同时有效，否则数据不完整

### 1.3 与CPU连接——写操作

![](../../images/Pasted%20image%2020260916145043.png)

**步骤**
1. CPU 把 32 位数据送入数据总线
2. CPU 把 18 位地址送入所有芯片
3. MREQ 有效，CS 有效，选中全部芯片
4. R/W = 0，WE 有效，写入数据
5. 每片芯片写入 1 位，拼成 32 位

**易错**
- 写操作时数据线方向是 CPU → 芯片
- 读操作时数据线方向是芯片 → CPU
- 位扩展不需要片选译码器，所有芯片同时工作

## 二、总结

![](../../images/Pasted%20image%2020260916145323.png)

| 维度 | 位扩展 |
| --- | --- |
| 目标 | 增加字长 |
| 字数 | 不变 |
| 芯片数 | 目标字长 / 单片字长 |
| 地址线 | 共用，位数不变 |
| 数据线 | 分片连接，总位数增加 |
| 片选 | 全部同时有效 |
| 典型场景 | 1 位/4 位芯片拼成 8/16/32 位 |

**易错**
- 位扩展不改变地址空间，只改变每个字的位数
- 芯片数由“字长比”决定，不是由“容量比”直接决定
- 地址线位数由字数决定；字数不变，地址线不变
