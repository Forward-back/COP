# 4.11 动态随机存储器——芯片实例及DRAM的发展

**考纲定位**：计算机组成原理 · 第 4 章 存储器（4.11）｜重要度 ★★★★｜常见考法：选择题（DRAM 引脚、地址复用、RAS/CAS、SDRAM/DDR 基本概念）

**一句话核心**：DRAM 用行/列地址分时复用减少引脚；SDRAM 与时钟同步，DDR 在时钟双沿传输数据

## 一、DRAM 芯片实例

![](../../images/Pasted%20image%2020260915171232.png)

**引脚与信号**
- 地址线：行地址和列地址分时复用同一组引脚
- $\overline{RAS}$：行地址选通，锁存行地址
- $\overline{CAS}$：列地址选通，锁存列地址
- $\overline{WE}$：写允许；读/写控制
- 数据线：输入/输出数据

**地址复用**
- 先送行地址，$\overline{RAS}$ 有效锁存
- 再送列地址，$\overline{CAS}$ 有效锁存
- 行、列交叉选中一个存储单元
- 地址线引脚数约为 $\max(\text{行地址位数},\text{列地址位数})$，而不是行+列

**公式**

$$\text{芯片容量} = 2^{\text{行地址位数}+\text{列地址位数}} \times \text{数据线位数}$$

**例题**

![](../../images/Pasted%20image%2020260915171630.png)

**易错**
- 地址复用不是“容量减半”；行、列地址合起来仍决定全部单元
- RAS/CAS 通常低电平有效
- 行地址和列地址不能同时送，必须分时
- 数据线位数决定字长，地址线决定字数

## 二、DRAM 的发展

### 2.1 发展

![](../../images/Pasted%20image%2020260915171746.png)

**提炼**
- 早期 DRAM 为异步，靠 RAS/CAS 时序控制
- SDRAM（同步 DRAM）与系统时钟同步，读写操作按节拍进行
- DDR SDRAM 在时钟上升沿和下降沿都传输数据，带宽翻倍
- DDR2/DDR3/DDR4/DDR5 通过预取、频率、电压等改进提升带宽

### 2.4 DDR SDRAM 的发展

![](../../images/Pasted%20image%2020260915172558.png)

**DDR 常见内存规格和参数**

![](../../images/Pasted%20image%2020260915172641.png)

**提炼**
- DDR = Double Data Rate，双倍数据率
- 在时钟上升沿和下降沿各传一次数据，等效带宽是 SDR 的两倍
- DDR2/3/4 主要通过预取位数、频率、电压改进；408 不考具体代数差异

**易错**
- 地址复用减少引脚，不减少容量
- SDRAM 的“同步”指与时钟同步，不是“与 CPU 同步”
- DDR 的双倍速率来自双沿传输，不是“频率翻倍”
- 内存条标称频率与实际时钟频率可能不同；DDR 标称常为等效数据率
