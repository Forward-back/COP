 **程序员可见性一览表**

|   分类    |          部件           |            说明            |
| :-----: | :-------------------: | :----------------------: |
| **可见**  |   通用寄存器（AX、R0~R31等）   |          指令直接读写          |
|         |       程序计数器 PC        |     存下条指令地址，跳转指令可修改      |
|         |       程序状态字 PSW       |    ZF/SF/OF/CF，决定条件跳转    |
|         |        堆栈指针 SP        | 指向栈顶，配合PUSH/POP/CALL/RET |
|         | 基址/变址寄存器（BX/BP/SI/DI） |        实现基址、变址寻址         |
|         |   段寄存器（CS/DS/SS/ES）   |          形成物理地址          |
| **不可见** |          MAR          |       存访存地址，硬件自动填充       |
|         |          MDR          |        暂存与主存交换的数据        |
|         |          IR           |    存当前指令，取指时自动装入，无法访问    |
|         |         Cache         |         对应用程序员透明         |
|         |     微指令寄存器、流水线寄存器     |       控制器/微架构内部实现        |
