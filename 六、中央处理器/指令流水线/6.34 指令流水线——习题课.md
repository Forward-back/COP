# 6.34 指令流水线——习题课

**考纲定位**：计算机组成原理 · 第 6 章 中央处理器（6.34）｜重要度 ★★★★｜常见考法：计算题（流水线周期、吞吐率、加速比、CPI）、概念题（数据通路/超标量/超流水）

**一句话核心**：流水线题先画时空图，再套 T=(k+n−1)τ；概念题先分清“超流水线提频率、多发射提每周期指令数”

## 一、例题一

![](../../images/Pasted%20image%2020261014192457.png)

**考什么**

- 四段流水线，各段耗时 90/80/70/60ns，求 CPU 时钟周期至少多少
- 流水线周期由最慢段决定（短板效应）

**错因**

- 取平均、取总和、取最快段
- 忘记流水线寄存器开销（题目忽略）
- 把“指令周期”与“时钟周期”混为一谈

**模板**

- 时钟周期 τ = max(各段延迟)（题目忽略段间寄存器时）
- 本题 τ = 90ns，答案 A

## 二、例题二

![](../../images/Pasted%20image%2020261014192520.png)

**考什么**

- 四段流水线，主频 1.03GHz，执行 100 条指令，无阻塞，求吞吐率
- 启动/排空：n 条指令需要 (k+n−1) 个时钟周期

**错因**

- 直接用 n×τ，忘记启动/排空
- 用 k×n
- 吞吐率单位写错（指令/秒 vs 条/周期）

**模板**

- 时钟周期 T = 1/1.03GHz
- 总周期数 = 4 + (100−1) = 103
- 总时间 = 103T；吞吐率 = 100/(103T) ≈ 1.0×10^9 条/秒，答案 C

## 三、例题三

![](../../images/Pasted%20image%2020261014192554.png)

**考什么**

- 指令流水线数据通路的组成
- 数据通路 vs 控制部件：控制信号生成不属于数据通路

**错因**

- 把控制部件算进数据通路
- 认为数据通路只有组合逻辑，忽略寄存器/时序逻辑
- 认为数据通路不包含寄存器组

**模板**

- 数据通路 = 操作元件 + 状态元件 + 连线；负责数据存储、传送、运算
- 控制部件负责产生控制信号，不属于数据通路
- 本题问“错误的是”，答案 A（包含生成控制信号的控制部件）

## 四、例题四

![](../../images/Pasted%20image%2020261014192633.png)

**考什么**

- 超标量 vs 超流水线 vs 动态调度
- 超流水线：缩短功能段处理时间/增加段数；超标量：一个时钟周期发射多条指令；动态调度：提高并行性

**错因**

- 把“缩短功能段处理时间”当成超标量
- 把“一个时钟周期发射多条指令”当成超流水线
- 认为超标量不需要动态调度/相关处理

**模板**

- 超流水线：提频率，CPI≈1
- 超标量（多发射）：提每周期指令数，CPI<1
- 动态调度：乱序执行/重命名，提高并行性
- 本题正确项为 II、III，答案 C

## 五、例题五

![](../../images/Pasted%20image%2020261014192703.png)

**考什么**

- 五段流水线执行一段指令，求寄存器值、时钟周期数、阻塞原因
- 数据相关（RAW）、load-use、控制相关对流水线的影响

**错因**

- 忘记取指/写回阶段，少算周期
- 把 load-use 当成普通 ALU 相关，漏停一拍
- 把控制相关与数据相关混为一谈
- 没有按“指令推进表”逐拍分析

**模板**

1. 画五段流水线时空图，标出每条指令的 IF/ID/EX/MEM/WB
2. 标出 RAW：后读 ∩ 前写；load-use 看是否紧邻
3. 有转发时：ALU 相关通常不停；load-use 停 1 拍
4. 控制相关：分支判断在哪段，决定冲刷/停顿几拍
5. 统计总周期数与寄存器最终值

## 六、通用易错清单

1. 流水线周期 ≠ 各段平均；取最慢段
2. 总周期数忘记启动/排空：(k+n−1)
3. 吞吐率/加速比公式用错
4. 超流水线 vs 多发射概念混
5. load-use 必须停 1 拍（有转发也不例外）
6. 控制相关不是数据相关；分支预测错误要冲刷
7. CPI<1 靠多发射，不是超流水线
