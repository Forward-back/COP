# 6.0 中央处理器导航与术语

**本章定位**：计算机组成原理 · 第 6 章 中央处理器｜408 重点：指令执行过程、数据通路、控制器（硬布线/微程序）、异常与中断、指令流水线

**一句话核心**：CPU 的主线是“指令怎么走（执行过程/数据通路）→ 谁发控制信号（控制器）→ 出事怎么办（异常中断）→ 怎么更快（流水线）”

## 二、核心概念链

**1. CPU 的两大部件**

- 数据通路：操作元件（组合逻辑）+ 状态元件（时序逻辑）+ 连线；负责数据存储、传送、运算
- 控制器：指令译码、时序产生、控制信号生成；只发信号，不处理数据

**2. 指令执行的层次**

- 指令周期：取指（+间址）+ 执行（+中断）
- 机器周期：取一个存储字的最短时间
- 时钟周期：最小时节拍
- 微操作：一个时钟周期内完成的最小操作；微操作 = 控制信号 + 数据通路动作

**3. 控制器的两条路线**

| 路线 | 核心 | 优点 | 缺点 | 典型 |
|---|---|---|---|---|
| 硬布线 | 组合逻辑/FSM 直接产生控制信号 | 快 | 难改、复杂 | RISC |
| 微程序 | 微指令存 CS，取微指令产生控制信号 | 灵活、规整 | 慢（访问 CS） | CISC |

**4. 微程序控制器的层次**

- 机器指令 ⊃ 微程序 ⊃ 微指令 ⊃ 微命令 ≈ 微操作
- CS：控制存储器（ROM）；μAR：微地址寄存器
- 微指令 = 操作控制字段 + 顺序控制字段（判别测试 + 下址）
- 下址字段法：微指令带下址；计数器法：μAR 自动 +1，跳转查 ROM/固定 0
- 直接表示：一位一命令；编码表示：互斥命令压缩 + 译码；混合表示：折中
- 水平型：一次多个微命令、微指令长、微程序短；垂直型：一次 1~2 个微操作、微指令短、微程序长

**5. 异常与中断**

- 异常（内中断）：同步，故障/自陷/终止；断点：Fault 当前指令，Trap 下一条，Abort 无意义
- 中断（外中断）：异步，可屏蔽 INTR / 不可屏蔽 NMI；断点：下一条指令
- 硬件三件事：关中断、保存断点（PC+PSW，408 口径）、中断识别/送 ISR 入口
- 软件：保护现场、开中断、服务、关中断、恢复现场、中断返回
- 跨章：通用中断分类/8259A/单级/多重见 IO 章 8.7-8.11

**6. 流水线**

- 五段：IF/ID/EX/MEM/WB；段间流水寄存器传数据 + 控制信号
- 性能：T=(k+n−1)τ；吞吐率 n/T；加速比 ≈ k（理想）；CPI≈1
- 三类冒险：结构（资源）、数据（RAW）、控制（分支）
- 数据冒险：ALU 相关靠旁路；load-use 停 1 拍；气泡 = 清空 ID/EX + 冻结 PC/IF-ID
- 超流水线：段数↑、频率↑、CPI≈1；多发射：宽度↑、CPI<1；两者可叠加

## 三、核心公式与计算

- 指令周期时间 = 机器周期数 × 时钟周期数 × 时钟周期
- 流水线：T = (k + n − 1) × τ；吞吐率 = n / T；加速比 = 非流水时间 / 流水时间
- CPI = 总时钟周期数 / 指令条数；多发射理想 CPI = 1/发射宽度
- 微指令控制字段位数：
  - 直接表示法：位数 = 微命令总数
  - 编码表示法：位数 = Σ ⌈log2（每组互斥微命令数 + 1）⌉
  - 混合表示法：直接位 + 各编码字段位数

## 四、术语表

**寄存器与数据通路**

- **可见寄存器**：指令可直接读写的寄存器（通用寄存器、PC、PSW、SP、段寄存器等）
- **不可见寄存器**：MAR、MDR、IR、Cache、流水线寄存器、微指令寄存器等
- **操作元件**：组合逻辑，无记忆，决定关键路径/时钟周期下限
- **状态元件**：时序逻辑，有时钟，决定时钟边界
- **单周期/多周期/流水线**：一条指令一个周期 / 分时复用多拍 / 多条指令重叠

**控制器与微程序**

- **微命令**：控制器发出的控制信号
- **微操作**：执行部件完成的具体动作
- **微指令**：一个时钟周期内的一组微命令 + 顺序控制信息
- **微程序**：完成一条机器指令的一组微指令
- **CS**：控制存储器，存放微指令的 ROM
- **μAR**：微地址寄存器，指向当前微指令
- **下址字段法**：微指令中显式给出下一微地址
- **计数器法**：μAR 自动 +1，跳转靠 ROM/固定 0
- **水平型微指令**：一次多个微命令，微指令长、微程序短
- **垂直型微指令**：一次 1~2 个微操作，微指令短、微程序长

**异常与中断**

- **异常（内中断）**：同步，由当前指令引发；故障/自陷/终止
- **中断（外中断）**：异步，由外部设备引发；INTR/NMI
- **断点**：返回地址与状态，408 口径为 PC+PSW，硬件保存
- **现场**：通用寄存器等工作环境，ISR 软件保存
- **EPC**：MIPS 风格的断点专用寄存器；嵌套时需软件转存
- **IE/IF**：中断允许标志；控制可屏蔽中断
- **中断隐指令**：关中断、保存断点、中断识别（硬件）

**流水线**

- **结构冒险**：争用同一部件/资源
- **数据冒险（RAW）**：后读前写，数据未就绪
- **控制冒险**：分支/跳转导致取指方向不确定
- **旁路/转发**：把中间结果直接送 ALU，绕过寄存器堆
- **气泡/Stall**：清空 ID/EX、冻结 PC/IF-ID，插入空操作
- **超流水线**：增加段数、缩短每段延迟、提高频率
- **多发射/超标量**：一个时钟周期发射多条指令，CPI<1
- **CPI/吞吐率/加速比**：每指令周期数 / 单位时间指令数 / 性能提升倍数
